## Problem Statement

Imagine you are an HR analyst at a large company and need a complete overview of all departments, including departments that currently have no employees assigned to them.

Write an SQL query to retrieve all departments along with the employees working in each department.

Display the following columns:

DepartmentID | DepartmentName | Location | EmployeeID | EmployeeName

Ensure that every department appears in the result, even if no employees belong to that department.

Sort the result by DepartmentID in ascending order and then by EmployeeID in ascending order.

## Solution

```js
SELECT 
    d.DepartmentID,
    d.DepartmentName,
    d.Location,
    e.EmployeeID,
    e.EmployeeName
FROM 
    Departments d
LEFT JOIN 
    Employees e ON d.DepartmentID = e.DepartmentID
ORDER BY 
    d.DepartmentID ASC,
    e.EmployeeID ASC;
```
