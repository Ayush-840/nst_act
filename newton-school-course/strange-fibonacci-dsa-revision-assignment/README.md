## Problem Statement

You are given a sequence of numbers. The first two terms of the sequence are provided as input.

From the third term onward, each term is computed using the rule:

current_term = 2 * last_term + 3 * second_last_term

Your task is to find and print the value of the n-th term of this sequence.

### Input
The first and only line of input contains three space-separated integers, a, b, n, where a is the first term of the sequence, b is the second term, and n is the position of the term to find.

### Output
Print a single integer — the value of the n-th term of the sequence.

### Example
Input
0 1 6
Output
61
Explanation
The sequence starts with 0, 1. 
Each next term is calculated as 2 * last_term + 3 * second_last_term. 
So the terms are: 0, 1, 2, 7, 20, 61. 
Thus the 6th term is 61.

Input
2 1 3
Output
8

# Your code here
def solve():
    a, b, n = map(int, input().split())

    if n == 1:
        print(a)
        return
    if n == 2:
        print(b)
        return

    second_last = a
    last = b

    for _ in range(3, n + 1):
        current = 2 * last + 3 * second_last
        second_last = last
        last = current

    print(last)


if __name__ == "__main__":
