## Problem Statement

You are working as a JavaScript developer for an online shopping platform.

The marketing team needs to send promotional emails to customers. But some products are age-restricted (for example, alcohol or adult-themed items).

To ensure compliance with legal regulations, the system must filter out customers under 18 years old.

Your task is to write a function that filters and returns only adult customers&rsquo; ages from a given list.

Write a function declaration named findAdultCustomers that takes one parameter, ages an array of customer ages.

Inside the function you must:

 * 
 Create a new, empty array (e.g., let adultList = [];).

 

 * 
 Loop through each value in the input array.

 

 * 
 If an age is 18 or older, add it to the adultList array.

 

 * 
 After the loop finishes, return the adultList array.

 

 

### Input
An array of integers representing customer ages.
Example: [12, 25, 17, 30, 19]

### Output
A new array containing only the ages of adult customers (ages 18 or above).
Example: [25, 30, 19]

### Example
Input: [12, 25, 17, 30, 19]
output: [25, 30, 19]

## Solution

```js
//create the function and give the exact same name as asked in the problem statement, return the final output through function. 

function findAdultCustomers(ages) {
  let adultList = [];

  for (let i = 0; i < ages.length; i++) {
    if (ages[i] >= 18) {
      adultList.push(ages[i]);
    }
  }

  return adultList;
}
```
