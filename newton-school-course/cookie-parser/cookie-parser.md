## Problem Statement

Write a function:

getCookie(header, name)

It should read a raw Cookie header and return the value of the cookie whose name exactly matches name.

Cookies are separated by semicolons (;) and may contain surrounding spaces.

Return null if the header is empty or the cookie is not found.

Requirements

 * 
 Match cookie names exactly.

 

 * 
 Ignore surrounding whitespace around cookie entries.

 

 * 
 Return only the cookie value.

 

 * 
 Do not hard-code cookie names or values.

 

Examples

getCookie("theme=dark; sid=abc", "sid");
// "abc"

getCookie("", "sid");
// null

getCookie("xsid=1; sid=2", "sid");
// "2"

getCookie("theme=dark; language=en", "missing");
// null

## Solution

```js
function getCookie(header, name) {
  if (typeof header !== 'string' || !header || typeof name !== 'string' || !name) {
    return null;
  }
  const pairs = header.split(';');
  for (let i = 0; i < pairs.length; i++) {
    const pair = pairs[i].trim();
    if (!pair) continue;
    const separatorIndex = pair.indexOf('=');
    if (separatorIndex === -1) continue;
    const cookieName = pair.slice(0, separatorIndex).trim();
    if (cookieName === name) {
      return pair.slice(separatorIndex + 1).trim();
    }
  }
  return null;
}
module.exports = { getCookie };
```
