## Problem Statement

Create an Express Router to update course information stored in a file named courses.json.

Assumptions:

 courses.json contains a JSON array of course objects.

 The Express application has already been configured with express.json(), so the request body is available through req.body.

 Import any required Node.js modules (such as fs and path) needed to read from and write to courses.json.

Task

Implement the following route:-

PUT /:id

 * Read the latest data from courses.json.

 * Find the course whose id matches the route parameter.

 Update only the matching course by merging the existing course object with the data received in req.body. Any fields not present in req.body should remain unchanged.

 Save the updated array back to courses.json.

 Return the updated course as a JSON response.

 You may use either the asynchronous (fs.readFile/fs.writeFile) or synchronous (fs.readFileSync/fs.writeFileSync) file system methods.

Constraints

For every request:-

 * Read the latest data from the file.

 * Update only the matching course.

 * Save the updated data back to the file.

 * Return the updated course as the response.

## Solution

```js
const express = require("express");
const fs = require("fs");
const path = require("path");
const router = express.Router();
const coursesFilePath = path.join(__dirname, "courses.json");
router.post("/", (req, res) => {
  try {
    const rawData = fs.readFileSync(coursesFilePath, "utf8");
    const courses = JSON.parse(rawData);
    if (!Array.isArray(courses)) {
      return res.status(500).json({ error: "Unable to update course data" });
    }
    const newCourse = req.body;
    courses.push(newCourse);
    fs.writeFileSync(coursesFilePath, JSON.stringify(courses, null, 2), "utf8");
    return res.status(201).json(newCourse);
  } catch (err) {
    return res.status(500).json({ error: "Unable to update course data" });
  }
});
module.exports = router;
```
