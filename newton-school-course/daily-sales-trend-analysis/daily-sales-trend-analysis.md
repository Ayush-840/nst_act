Task - 
Write one SQL query using the daily_sales table to generate a chronological sales report.

 
Your query must return one row for every sale date and include the following:

 * Sale date and actual sales: Display the date and the number of units sold on that day.

 * Recent sales trend: Calculate the average units sold using the current day and the two immediately preceding days. For the first two days, use only the available preceding records. Display this as moving_avg_3d, rounded to 1 decimal place.

 * Cumulative performance: Calculate the total units sold from the first day of the dataset up to the current day. Display this as running_total.

 * Day-over-day change: Calculate how many units today&#39;s sales increased or decreased compared with the previous day&#39;s sales. Display this as change_vs_prev_day. The first day should have no previous-day value.

 * Difference from recent trend: Calculate the difference between today&#39;s actual sales and today&#39;s own 3-day moving average. Display this as variance_vs_moving_avg, rounded to 1 decimal place.

 * Complete chronological report: Order the final result by sale_date in ascending order. Do not filter out any day, including the first day.

### Output
Expected output columns:

sale_date | units_sold | moving_avg_3d | running_total | change_vs_prev_day | variance_vs_moving_avg

## Solution

```js
select
sale_date,
units_sold,
round(
    avg(units_sold) over(
        order by sale_date
        rows between 2 preceding and  current row
    ),1
)as moving_avg_3d,

sum(units_sold) over(
    order by sale_date
)as running_total,
units_sold - LAG(units_sold, 1) OVER (
        ORDER BY sale_date
    ) AS change_vs_prev_day,

round(
    units_sold - avg(units_sold) over(
        order by sale_date
        rows between 2 preceding and current row
    ),1
)as variance_vs_moving_avg
from daily_sales
order by sale_date asc;
```
