## Problem Statement

You are given an array of numerical scores and need to implement the function processScores. This function applies multiple callback functions to modify the scores.

Functionality:

The function should take in:

 An array of numbers representing the scores.

 n callback functions, where each function modifies the scores in some way.

Each callback function should be applied to every element in the scores array, transforming them according to the provided logic.

### Input
First line of input is an array of numerical scores.
A series of callback functions, each written on a new line in a compact single-line format.
last line is a string "done" representing end of input

### Output
a modified array after subjecting each element to given callback functions

### Example
Input:
[50, 75, 90, 100]
function(score) { return score + 5; }
function(score) { return score * 2; } 
(score) =&gt; Math.round(score) 
done

Output:
[ 110, 160, 190, 210 ]

Explanation:
Initial array: [50, 75, 90, 100]
Step 1: Add 5 to each element → [55, 80, 95, 105]
Step 2: Multiply each element by 2 → [110, 160, 190, 210]
Step 3: Round each element (no change as all are whole numbers) → [110, 160, 190, 210]
Final output: [110, 160, 190, 210]

## Solution

```js
function processScores(scores, ...callbacks) {
  let res = scores;
  for (let cb of callbacks) {
    res = res.map(cb);
  }
  return res;
}
```
