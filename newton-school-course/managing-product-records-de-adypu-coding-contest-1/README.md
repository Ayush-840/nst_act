## Problem Statement

You are working with a retail management system that keeps track of products available in multiple store locations. The system uses a table named Products to store the details of each product.

The schema of the Products table is as follows:

 
 
 Column Name
 Description

 SERIAL PRIMARY KEY &mdash; Automatically generated unique identifier for each product
 
 
 product_name
 VARCHAR(100), NOT NULL &mdash; Name of the product
 
 
 store_location
 VARCHAR(50) &mdash; Location of the store (e.g., New York, San Francisco, Chicago)
 
 
 price
 DECIMAL(8,2) &mdash; Price of the product
 
 
 quantity_in_stock
 INT &mdash; Number of units available in the store
 
 

Tasks:

Perform the following actions on the Products table:

 * 
 Update the price of "Wireless Mouse" to 18.99 and set quantity_in_stock to 50.

 

 * 
 Delete the record for "Desk Lamp" and insert a new product "Ergonomic Chair" in the Chicago store with price = 129.99 and quantity_in_stock = 20.

 

 * 
 Display all the records from the Products table once the changes are made.

## Solution
