## Problem Statement

Akash has expanded his company and now tracks not only employees and departments but also projects assigned to employees.

employees:

[

 { "_id": 1, "name": "Alice", "department_id": 101 },

 { "_id": 2, "name": "Bob", "department_id": 102 },

 { "_id": 3, "name": "Charlie", "department_id": 101 }

]

departments:

[

 { "_id": 101, "department_name": "Sales" },

 { "_id": 102, "department_name": "Engineering" }

]

projects:

[

 { "_id": 1001, "project_name": "Website Redesign", "employee_id": 1 },

 { "_id": 1002, "project_name": "New CRM System", "employee_id": 2 },

 { "_id": 1003, "project_name": "Lead Generation Campaign", "employee_id": 3 }

]

Write a MongoDB aggregation query using $lookup (nested) to get a list of employees with their department name and all projects assigned to them in the following format:

[

 { "name": "Alice", "department_name": "Sales", "projects": ["Website Redesign"] },

 { "name": "Bob", "department_name": "Engineering", "projects": ["New CRM System"] },

 { "name": "Charlie", "department_name": "Sales", "projects": ["Lead Generation Campaign"] }

]

 

### Output
[
 { "name": "Alice", "department_name": "Sales", "projects": ["Website Redesign"] },
 { "name": "Bob", "department_name": "Engineering", "projects": ["New CRM System"] },
 { "name": "Charlie", "department_name": "Sales", "projects": ["Lead Generation Campaign"] }
]

## Solution

```js
db.employees.aggregate([
  {
    $lookup: {
      from: "departments",
      localField: "department_id",
      foreignField: "_id",
      as: "department_info"
    }
  },
  {
    $unwind: "$department_info"
  },
  {
    $lookup: {
      from: "projects",
      localField: "_id",
      foreignField: "employee_id",
      as: "project_info"
    }
  },
  {
    $project: {
      _id: 0,
      name: 1,
      department_name: "$department_info.department_name",
      projects: {
        $map: {
          input: "$project_info",
          as: "proj",
          in: "$$proj.project_name"
        }
      }
    }
  }
])
```
