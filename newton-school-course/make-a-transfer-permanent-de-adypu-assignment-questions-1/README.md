## Problem Statement

You are given an accounts table (acc_id, holder, balance). Inside a transaction, transfer 500 from account 1 to account 2 (subtract 500 from account 1, add 500 to account 2), then COMMIT so the change becomes permanent. Return all accounts (acc_id, holder, balance) 

The accounts table initially contains:

+--------+--------+---------+
| acc_id | holder | balance |
+--------+--------+---------+
| 1 | Aarav | 3000 |
| 2 | Priya | 1000 |
+--------+--------+---------+

### Output
BEGIN
UPDATE 1
UPDATE 1
COMMIT
 acc_id | holder | balance 
--------+--------+---------
 1 | Aarav | 2500
 2 | Priya | 1500
(2 rows)

## Solution

```js
// ─── 1 ───
begin;
update accounts set balance=balance-500 where acc_id=1;
update accounts set balance=balance+500 where acc_id=2;
commit;
select acc_id, holder, balance from accounts; 

// ─── 2 ───
BEGIN
UPDATE 1
UPDATE 1
COMMIT
 acc_id | holder | balance 
--------+--------+---------

      2 | Priya  |    1500
(2 rows)
```
