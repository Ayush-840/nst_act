Task:
Write a SQL query to display each account along with its account_holder, opened_date, and balance. Also calculate a running total of balances based on the account opening date.

The running total should include the balance of the current account and all accounts opened before it.

Display the following columns:

 running_total &mdash; cumulative sum of balance in order of opened_date

Order the final results by opened_date in ascending order.

## Solution

```js
SELECT 
    account_holder,
    opened_date,
    balance,
    SUM(balance) OVER (ORDER BY opened_date ASC) AS running_total
FROM 
    accounts
ORDER BY 
    opened_date ASC;
```
