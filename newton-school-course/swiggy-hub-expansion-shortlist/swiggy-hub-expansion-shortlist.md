## Problem Statement

Swiggy is deciding which cities to open new delivery hubs in. The first input is the list of cities the company has ever delivered to. Delivery addresses come from a free-text field filled by customers, so the same city shows up in different letter cases, and older orders were saved before the city field became mandatory.

Table

orders(
 id INT PRIMARY KEY,
 customer VARCHAR(50) NOT NULL,
 city VARCHAR(50)
)

Return the list of cities delivered to, each city once, in uppercase, in a single column named city. Orders with no city recorded are ignored.

Order by city ascending.

Why this matters: "how many cities do we serve" ends up in a board deck. Typing differences and missing values change that number unless the query decides what to do with them.

### Example
Sample Input:

orders

idcustomercity
1TanviPune
2OmkarNAGPUR
3Riyapune

Sample Output:

city
NAGPUR
PUNE

## Solution

```js
-- Write your query below. End it with a semicolon.

select distinct(upper(city)) as city from orders
where city is not null
order by city asc;
```
