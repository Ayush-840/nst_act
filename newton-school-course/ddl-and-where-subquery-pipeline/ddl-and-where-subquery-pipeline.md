## Problem Statement

Scenario: You are working with the Newton Bank database. The bank wants to identify accounts that have never made a transaction. The transactions table may contain records with NULL account IDs, so your query should correctly handle these NULL values while identifying accounts with no matching transaction records.

Table: accounts

+----------------+---------------+
| Column | Type |
+----------------+---------------+
| account_id | INT (PK) |
| account_holder | VARCHAR(50) |
| branch | VARCHAR(20) |
| account_type | VARCHAR(20) |
| account_status | VARCHAR(10) |
| balance | DECIMAL(12,2) |
| opened_date | DATE |
+----------------+---------------+

Table: transactions

+-------------+----------------------+
| Column | Type |
+-------------+----------------------+
| txn_id | INT (PK) |
| account_id | INT (FK → accounts) |
| txn_amount | DECIMAL(12,2) |
| txn_type | VARCHAR(10) |
| txn_date | DATE |
+-------------+----------------------+

Task

 Retrieve all accounts that have no matching transaction records in the transactions table. Use a NOT IN subquery and ensure that any NULL account IDs in the subquery do not affect the results.

### Output

## Solution

```js
// ─── 1 ───
select
account_id,
account_holder,
branch,
account_type,
account_status,
balance,
opened_date 
from accounts
where account_id NOT IN(
    SELECT account_id
    FROM transactions
    WHERE account_id IS NOT NULL
);
```
