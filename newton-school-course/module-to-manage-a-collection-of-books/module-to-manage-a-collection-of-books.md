## Problem Statement

Create a Node.js server using the built-in http module to manage a collection of books stored in memory.

The boilerplate includes a predefined books array stored in memory. Your task is to use this array to implement the required API endpoints.

Each book contains the following properties:

 * id (integer)

 * title (string)

 * author (string)

Implement the following API endpoints:

GET /books

Return the complete list of books as a JSON array with a status code of 200 OK.

GET /books/:id

Extract the book ID from the URL and return the corresponding book as JSON.

Handle the following scenarios for GET /books/:id:

 * If a book with the given ID exists, return the book with a status code of 200 OK.

 * If no book exists with the given ID, return a status code of 404 Not Found and an appropriate JSON error message.

}
 

 * If the ID provided is not a valid number (for example, /books/abc), return a status code of 400 Bad Request and an appropriate JSON error message.
