## Problem Statement

A retail analytics team is building a NULL-safe report over an employee performance table. Some bonus and target values are missing or stored as 0, which can cause misleading calculations. The report must handle all NULL scenarios gracefully.

employee_performance table:

+--------+--------------+----------------+--------------+-------+
| emp_id | emp_name | sales_achieved | sales_target | bonus |
+--------+--------------+----------------+--------------+-------+
| 101 | Aarav Sharma | 120000 | 100000 | 10000 |
| 102 | Priya Verma | 85000 | 100000 | NULL |
| 103 | Rahul Mehta | 50000 | 0 | 3000 |
| 104 | Sneha Gupta | 75000 | NULL | NULL |
| 105 | Vikram Singh | 110000 | 100000 | 8000 |
+--------+--------------+----------------+--------------+-------+

Task: Employee Bonus and Sales Achievement Analysis

Write a PostgreSQL query to generate an employee sales performance report.

Display the employee name where bonus is null.

Write query to display -

 * Display the employee name where bonus is null.

 * Write one query for all mentioned below task -

 * Display the employee name.

 * Create a bonus_display column using COALESCE():
 
 * Display the bonus amount when a bonus exists.

 * Display &#39;Not Awarded&#39; when the bonus is NULL.

 
 

 * Create an achievement_pct column that:
 
 * Calculates (sales_achieved / sales_target) * 100.

 * Uses NULLIF() to prevent a division-by-zero error when sales_target is 0.

 * Rounds the result to 1 decimal place using ROUND().

 * Uses COALESCE() to display 0 when the calculation results in NULL.

 
 

 * Exclude employees whose sales_target is NULL.

 * Sort the result by achievement_pct in descending order.

The report should allow the analytics team to identify employees who have not yet received a bonus.

## Solution

```js
select 
emp_name
from employee_performance 
where bonus is null;

select 
emp_name,
    case
       when bonus is not null then bonus::text
       ELSE 'Not Awarded'
    end as bonus_display ,

    case 
       when sales_target is null or  sales_target=0 then 0
       else ROUND((sales_achieved::numeric / sales_target) * 100, 1)
    end as achievement_pct

from employee_performance
where sales_target is not null
ORDER by achievement_pct desc;
```
