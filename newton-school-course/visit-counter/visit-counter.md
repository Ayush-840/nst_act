## Problem Statement

Build a GET /visits endpoint that tracks how many times a user visits using cookies and an in-memory JavaScript object.

Requirements

 * 
 Use a cookie named sid to identify each session.

 

 * 
 If the sid cookie is missing or does not match an existing session:

 
 * 
 Create a new session with { count: 1 }.

 

 * 
 Generate a new unique session ID.

 

 * 
 Send the new sid back as a cookie.

 

 * 
 Return { "count": 1 }.

 

 
 

 * 
 If the sid matches an existing session:

 
 * 
 Increase its count by 1.

 

 * 
 Return the updated count.

 

 
 

 * 
 Each session must maintain its own visit count.

 

 * 
 Only the sid cookie should identify the session. Other cookies must be ignored.

 

 * 
 All responses must have HTTP status 200 and a JSON body containing the count.

 

Example

First request (without a session cookie):

{ "count": 1 }

Next request with the same session cookie:

{ "count": 2 }

Another request with the same session:

{ "count": 3 }

Sessions only need to exist while the server is running.

Generating a Session ID

You can use Node.js&#39;s built-in crypto module to generate a unique session ID:

const crypto = require("crypto");
const sid = crypto.randomUUID();
