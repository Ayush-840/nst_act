## Problem Statement

Build a POST /checkin endpoint on an Express server that lets a student check into class.

Endpoint: POST /checkin

Request body: { "name": "&lt;student name&gt;" }

The handler must:

 * Validate input: name is required and must be a string containing at least one non-whitespace character after calling trim(). Any other type (number, null, array, object, missing key) or a blank/whitespace-only string is invalid.

 
 * On invalid input: respond with HTTP 400 and a JSON body containing an error key. No studentArrived event should be emitted.

 
 

 * Capture the current time the request was processed.

 * Determine attendance status by comparing the captured time against a 9:00:00 AM cutoff (server local time):
 
 * Time &le; 9:00:00 AM &rarr; "On Time"

 * Time &gt; 9:00:00 AM &rarr; "Late"

 
 

 * The boilerplate already provides an attendanceSystem EventEmitter instance. Use this instance to emit the studentArrived event., passing an object containing the (trimmed) name, the captured time, and the computed status.

 * Respond immediately with HTTP 200 and a JSON body of the shape:

 {
 "message": "Check-in recorded",
 "student": {
 "name": "Riya Sharma",
 "time": "2024-01-01T03:29:59.000Z",
 "status": "On Time"
 }
 }

The response must not wait on any asynchronous work triggered by the studentArrived event.

Only POST /checkin should exist, no other HTTP methods should be handled on this path.
