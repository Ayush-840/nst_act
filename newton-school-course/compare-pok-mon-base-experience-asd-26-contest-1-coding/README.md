## Problem Statement

A trainer is deciding which Pok&eacute;mon to use in battle based on their experience. Implement an asynchronous function comparePokemonExperience that accepts two Pok&eacute;mon names as arguments, fetches their data from the PokeAPI https://pokeapi.co/api/v2/pokemon/name for each, and compares their base_experience values.

The function should return an object:

if one Pok&eacute;mon has a higher base_experience 

 return an object in the given format: { winner: &lt;pokemon_name&gt;, base_experience: &lt;value&gt; }

if both have equal base_experience

 return an object in the given format: { tie: true, base_experience: &lt;value&gt; }

Example URL: "https://pokeapi.co/api/v2/pokemon/bulbasaur"

### Input
Two strings separated by one space representing valid Pokémon names

### Output
an Object with either 
{ winner: string, base_experience: number } 
or 
{ tie: boolean, base_experience: number }

### Example
Input: 

pikachu charmander

Output: 

{ winner: 'pikachu', base_experience: 112 }

## Solution

```js
async function comparePokemonExperience(name1, name2) {
  let fst =await fetch(`https://pokeapi.co/api/v2/pokemon/${name1}`).then((res)=> res.json())
  .then((data)=>{
    let out=data.base_experience
    return out
  })

  let snd = await fetch(`https://pokeapi.co/api/v2/pokemon/${name2}`).then((res)=>res.json())
  .then((data)=>{
    let out=data.base_experience
    return out
  })

  if(fst>snd){
    return (`{ winner: '${name1}', base_experience: ${fst} }`)
  }else{
    return (`{ winner: '${name2}', base_experience: ${snd} }`)
  }

}
```
