## Problem Statement

Bunty has hidden a word in a long string by placing its letters at every even index. Write a program to extract the hidden word.

Note:

Since this is a Functional Problem, you do not need to take any input, just return the required string.

### Input
The First line of input contains a string of alphanumeric characters, with the letters of the hidden word at every even index.

### Output
Don't print the string , just return the string representing the hidden word formed by the characters at every even index.

### Example
Input
h1e2l3l4o5

Output
hello

## Solution

```py
def extract_hidden_word(s):
    ans=""
    for i in range(len(s)):
        if i%2==0:
            ans +=s[i]
    return ans
```
