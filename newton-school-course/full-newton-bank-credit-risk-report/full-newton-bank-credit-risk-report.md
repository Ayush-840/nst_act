## Problem Statement

Scenario: The credit risk team needs a report of Active accounts that perform above their branch average and have at least one recorded transaction. For risk review, each qualifying account should be classified as High Value if its balance exceeds twice its branch&#39;s average balance; otherwise it should be classified as Above Average.

Tasks:

1. Query accounts returning account_holder, branch, account_type, and balance.

2. Add a branch_avg column using a correlated scalar subquery in the SELECT list.

3. Add a balance_diff column computed as balance minus branch_avg.

4. Filter the results to Active accounts only.

5. Add a correlated WHERE subquery so only accounts with balance above their branch average are returned.

6. Add a correlated EXISTS condition so only accounts with at least one row in transactions are included.

7. Add a risk_flag CASE column: &#39;High Value&#39; if balance exceeds twice the branch average, and &#39;Above Average&#39; otherwise.

8. Round branch_avg and balance_diff to 2 decimal points.

## Solution

```js
SELECT 
    a.account_holder,
    a.branch,
    a.account_type,
    a.balance,
    ROUND((
        SELECT AVG(sub_a.balance)
        FROM accounts sub_a
        WHERE sub_a.branch = a.branch
    ), 2) AS branch_avg,
    ROUND(
        a.balance - (
            SELECT AVG(sub_a.balance)
            FROM accounts sub_a
            WHERE sub_a.branch = a.branch
        ), 2
    ) AS balance_diff,
    CASE 
        WHEN a.balance > 2 * (
            SELECT AVG(sub_a.balance)
            FROM accounts sub_a
            WHERE sub_a.branch = a.branch
        ) THEN 'High Value'
        ELSE 'Above Average'
    END AS risk_flag
FROM 
    accounts a
WHERE 
    a.account_status = 'Active'
    AND a.balance > (
        SELECT AVG(sub_a.balance)
        FROM accounts sub_a
        WHERE sub_a.branch = a.branch
    )
    AND EXISTS (
        SELECT 1
        FROM transactions t
        WHERE t.account_id = a.account_id
    );
```
