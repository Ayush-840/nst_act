## Problem Statement

You are given a value amount and an infinite supply of currency denominations {1, 2, 5, 10, 20, 50, 100, 200, 500, 2000}.

Your task is to determine the minimum number of coins and/or notes required to make up the exact value of amount.

### Input
User Task
Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function
coinChange(), which takes an integer amount as its parameter.

Custom Input
The first and only line contains a single integer amount:
An integer representing the total value for which change is to be made using the available denominations.

### Output
Return an integer representing the minimum number of coins required to make up the given amount.

### Example
Input
43
Output
4
Explanation
You can make 43 using denominations: 20 + 20 + 2 + 1
Total coins/notes used = 4

Input
3
Output
2
Explanation
You can make 3 using denominations: 2 + 1
Total coins/notes used = 2

## Solution

```py
def coinChange(amount):
    val = [2000,500,200,100,50,20,10,5,2,1]
    count = 0
    for coin in (val):
        if amount == 0:
            break
        if amount >= coin:
            count += amount // coin
            amount = amount%coin
    return count
```
