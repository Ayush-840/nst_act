## Problem Statement

You are given a MongoDB collection named players that stores cricket player statistics. Each document in the collection has the following structure:

{
 "name": String,
 "team": String,
 "score": Number // Score in the latest match
}

As part of a data correction task: 

Ensure that no player&#39;s score exceeds 100 (i.e., if a player&#39;s score is more than 100, set it to 100).

Write a MongoDB update query that enforces the above condition across all players.

After updating, retrieve the top 5 players with the highest scores. After updating, fetch only the name, team, and score fields.

## Solution

```js
db.players.updateMany(
  {},
  [
    {
      $set: {
        score: { $min: ["$score", 100] }
      }
    }
  ]
);

db.players.find(
  {},
  {
    _id: 0,
    name: 1,
    team: 1,
    score: 1
  }
).sort({ score: -1 }).limit(5);
```
