## Problem Statement

Write a program that creates an HTTP server. The server should accept POST requests containing a JSON request body representing a student in the following format:

{
 "name": string,
 "gpa": number
}

Rules

 * 
 name must be present and be a non-empty string.

 

 * 
 gpa must be present and be a number between 0 and 4 (inclusive).

 

 * 
 server must be running on port: 3000

 

Response Requirements

Valid Data: If the request body satisfies all the validation rules, return:

 * 
 Status Code: 200 OK

 

 * 
 Content-Type: application/json

 

Response Body:

{
 "status": "success"
}

Invalid Data: If the request body contains malformed JSON, request method is not POST or the validation rules are not satisfied.

return:

 * 
 Status Code: 400 Bad Request

 

 * 
 Content-Type: application/json

 

Response Body:

{
 "status": "failed"
}

Notes

 * 
 The server only needs to handle POST requests.

 

 * 
 All responses must be valid JSON.

## Solution

```js
const http = require("http");
const fs = require("fs");
const path = require("path");
const PORT = process.env.PORT || 3000;
const CHAT_FILE_PATH = path.join(__dirname, "chat.txt");
const server = http.createServer((req, res) => {
  const pathname = (req.url || "/").split("?")[0];
  // GET /history -> read and return chat.txt
  if (req.method === "GET" && pathname === "/history") {
    fs.readFile(CHAT_FILE_PATH, "utf8", (err, data) => {
      if (err) {
        res.writeHead(500, { "Content-Type": "text/plain" });
        return res.end("Unable to load chat history");
      }
      res.writeHead(200, { "Content-Type": "text/plain" });
      return res.end(data);
    });
    return;
  }
  // Any other route or HTTP method (e.g., POST /history, unknown routes)
  res.writeHead(404, { "Content-Type": "text/plain" });
  res.end("Route Not Found");
});
server.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
```
