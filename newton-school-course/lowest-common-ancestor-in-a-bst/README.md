## Problem Statement

Given a Binary Search Tree and two integers n1 and n2, your task is to find the lowest common ancestor (LCA) of the two given integers.

The lowest common ancestor is defined between two nodes p and q as the lowest node in T that has both p and q as descendants (where we allow a node to be a descendant of itself).

Note: Values n1 and n2 may or may not be present.

### Input
Your Task
Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function LCA(), which takes the root, n1 and n2 as the input parameter.

The next line consists of space-separated integers denoting the level order traversal of the tree, where non-negative values represent node values, and -1 indicates a null node.
The next line of input contains n1 and n2 representing the node values.
Note: Once a node is marked as -1, no further information about its children is provided.

### Output
Return the node containing LCA of n1 and n2 if both values exist otherwise None.
