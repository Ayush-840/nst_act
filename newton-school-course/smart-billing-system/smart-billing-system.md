## Problem Statement

You are building a Smart Billing System for an online shopping platform.
Each customer purchases multiple items, and for each item, the system stores:

 
 Its price

 

 
 Its quantity purchased

 

You need to write a program that calculates the final bill based on this data.

Your task is to create a function declaration named calculateBill that:

 
 Takes two parameters:

 
 
 prices: an array of item prices

 

 
 quantities: an array of item quantities

 

 
 

 
 Both arrays are of the same length, the first element in each array corresponds to the same product.

 
 
 For example, prices[0] is the price of item 1, and quantities[0] is its quantity.

 

 
 

 
 The function should calculate:

 
 
 Subtotal: Sum of (price[i] * quantity[i]) for all items

 

 
 Discount: 10% of subtotal, only if subtotal &gt; ₹1000

 

 
 Payable amount: Subtotal &minus; Discount

 

 
 

 
 Return these three values inside an array, where:

 
 
 Index 0 &rarr; Subtotal

 

 
 Index 1 &rarr; Discount

 

 
 Index 2 &rarr; Payable Amount

 

 
 

### Input
Input contains 2 lines

Line 1: Array of prices
Line 2: Array of quantities

Example:
[250, 100,300]
[2, 1,3]

### Output
Return an array of three numbers:
[subtotal, discount, payable]

Example:
[1500, 150, 1350]

## Solution

```js
//write the function here with same name and return the expected value
function calculateBill(prices, quantities) {
  let subtotal = 0;

  for (let i = 0; i < prices.length; i++) {
    subtotal += prices[i] * quantities[i];
  }

  let discount = subtotal > 1000 ? subtotal * 0.1 : 0;
  let payable = subtotal - discount;

  return [subtotal, discount, payable];
}
```
