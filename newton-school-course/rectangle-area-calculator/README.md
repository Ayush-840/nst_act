## Problem Statement

Write a program that calculates the area of a rectangle given its length and width.

The program should prompt the user to enter the length and width of the rectangle, and then calculate and print the area.

### Input
The first line of input contains a single integer, representing the length of rectangle.
The second line of input contains a single integer, representing the width of rectangle.

### Output
Print the answer in following format:
"Area of the rectangle is: [calculated area]"

### Example
Input
5
3
Output
Area of the rectangle is: 15

## Solution

```js
length=int(input())
width=int(input())
area=length*width
print("Area of the rectangle is:",area)
```
