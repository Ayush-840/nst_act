## Problem Statement

You are given a MongoDB collection named users. Each document in the collection has the following structure: 

{
 "name": String,
 "age": Number,
 "email": String,
 "tags": [String] // An array of tags/interests assigned to the user
}

Write a MongoDB query to find all users who meet the following criteria:

Their age is greater than or equal to 30, and they have exactly 3 tags in the tags array.

Return only the name, age, and tags fields (exclude _id).

## Solution

```js
db.users.find(
  {
    age: { $gte: 30 },
    tags: { $size: 3 }
  },
  {
    _id: 0,
    name: 1,
    age: 1,
    tags: 1
  }
);
```
