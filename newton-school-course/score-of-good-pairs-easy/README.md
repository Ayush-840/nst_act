## Problem Statement

You are given an array of integers nums of size n. A pair (i, j) is called a good pair if:

 i &lt; j

 nums[i] == nums[j]

The score of a good pair is defined as j - i.

Your task is to find the sum of the scores of all good pairs in the array.

### Input
User Task
This is a function problem. You don’t need to handle any input or output.
You are required to complete the function findScoreSum(), which takes an array nums as a parameter and returns an integer — the sum of scores of all subarrays.

Custom Input
The first line of input contains an integer: n.
The second line contains n space-separated integers representing the elements of the array nums.

### Output
Return an integer denoting the sum of scores of all subarrays.

### Example
Input:
6
1 2 1 2 1 2

Output:
16

Explanation:
Good pairs and their scores:
(0, 2): score = 2
(0, 4): score = 4
(2, 4): score = 2
(1, 3): score = 2
(1, 5): score = 4
(3, 5): score = 2
Total = 2 + 4 + 2 + 2 + 4 + 2 = 16

## Solution

```py
def findScoreSum(nums):
    ans = 0
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] == nums[j]:
                ans += j - i 
    return ans
```
