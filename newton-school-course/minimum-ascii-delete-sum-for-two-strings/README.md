## Problem Statement

Given two strings s1 and s2, return the lowest ASCII sum of deleted characters to make two strings equal.

### Input
User Task:
Since this will be a functional problem, you don't have to take input. You just have to complete the function minimumDeleteSum() that takes strings "s1" and "s2" as parameters.

Custom Input:
First line will contain a string s1.
Second line will contain a string s2.

### Output
Return the lowest ASCII sum of deleted characters to make two strings equal.

### Example
Input: 
sea
eat
Output: 
231
Explanation: 
Deleting "s" from "sea" adds the ASCII value of "s" (115) to the sum.
Deleting "t" from "eat" adds 116 to the sum.
At the end, both strings are equal, and 115 + 116 = 231 is the minimum sum possible to achieve this.

def minimumDeleteSum(s1,s2):
    if len(s1) < len(s2):
        s1, s2 = s2, s1
    
    n, m = len(s1), len(s2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        dp[i][0] = dp[i - 1][0] + ord(s1[i - 1])
    
    for j in range(1, m + 1):
        dp[0][j] = dp[0][j - 1] + ord(s2[j - 1])
    
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = min(dp[i - 1][j] + ord(s1[i - 1]), dp[i][j - 1] + ord(s2[j - 1]))
    
    return dp[n][m]
