## Problem Statement

You are given an integer array arr containing N elements. Your task is to calculate the sum of all even numbers present in the array.

### Input
User Task
Since this is a functional problem, you do not need to take input. Your task is to complete the function even_sum() that takes an integer array arr as an input parameter.

Custom Input
The first line of input contains an integer N, representing the number of elements in the array.
The second and final line of input contains N space-separated integers, representing the elements of the array.

Constraints
1 \le N \le 10^5
-10^5 \le arr[i] \le 10^5

### Output
Return an integer, representing the sum of all even numbers present in the array.

### Example
Input
5
32 17 0 3 7
Output
32
Explanation
The array contains only two even numbers: 32 and 0. Their sum is 32.

Input
5
0 2 4 6 0
Output
12
Explanation
All the elements present in the array are even and their sum is 0 + 2 + 4 + 6 + 0 = 12.

## Solution

```py
def even_sum(arr):
    return sum(x for x in arr if x % 2 == 0)
```
