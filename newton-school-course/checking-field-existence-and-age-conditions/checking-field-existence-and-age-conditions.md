## Problem Statement

You are given a MongoDB collection named users. Each document in the collection contains user information with the following structure:

{
 "name": String,
 "middleName": String (optional),
 "age": Number,
 "email": String
}

Write a MongoDB query to find all users who meet both of the following conditions:

The field middleName exists in the document, and the user&#39;s age is a multiple of 5 (i.e., divisible by 5).

Return only name, middleName, and age fields (exclude _id):

## Solution

```py
db.users.find(
  {
    middleName: { $exists: true },
    age: { $mod: [5, 0] }
  },
  {
    _id: 0,
    name: 1,
    middleName: 1,
    age: 1
  }
);
```
