## Problem Statement

Given a 2d array of intervals, named intervals where intervals[i] = [starti, endi], return the minimum number of intervals you need to remove to make the rest of the intervals non-overlapping.

Note: Intervals are non-overlapping even if they have a common point. For example, [1, 3] and [2, 4] are overlapping, but [1, 2] and [2, 3] are non-overlapping.

### Input
User Task
This is a functional problem. You don't have to take any input. You are required to complete the function remove_overlapping() which takes the 2D vector of integers representing intervals as parameter.

Custom Input
The first line of the input contains an integer n representing size of array interval.
Next n lines contain two space-separated integers each, representing the elements of array intervals

Constraints:
1 \le n \le 5 * 10^4
intervals[i].length == 2
-5 * 10^4 

### Output
Return an integer, representing the minimum number of intervals you need to remove to make the rest of the intervals non-overlapping.

### Example
Input
2
1 2
2 4
Output
0
Explanation
Given two intervals are non-overlapping, thus no intervals need to be removed.

Input
3
1 2
2 4
1 4
Output
1
Explanation
The last interval [1, 4] overlaps with the first two intervals, thus we need to remove it.

## Solution

```py
def remove_overlapping(intervals):
    intervals.sort(key=lambda x: x[1])
    cnt=0
    end = intervals[0][1]
    for i in range(1,len(intervals)):
        if intervals[i][0] < end:
            cnt+=1
        else:
            end=intervals[i][1]
    return cnt
```
