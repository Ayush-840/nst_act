## Problem Statement

A software company manages licenses that can be activated on user devices. Each license can be active on only one device at a time, but previous device mappings must be retained for history.

You have been given a set of license activation requests. Process each request and update the database while maintaining the registry rules.

Activation Requests

 * LIC-1001 &rarr; MacBook-Air-01

 * LIC-2001 &rarr; MacBook-Pro-02

 * LIC-1002 &rarr; Ubuntu-Laptop-01

Requirements

 * Create the license if it does not already exist.

 * Create the device if it does not already exist.

 * If the requested license-device mapping already exists, activate it.

 * If the license is currently active on another device, deactivate that mapping before activating the requested device.

 * Deactivation must be done by setting is_active to FALSE. Do not delete old mappings.

 * Create a new license-device mapping when the requested mapping does not exist.

 * Process all activation requests inside a single transaction.

Note: Inspect the existing data before deciding what needs to be created or updated and in which order. Do not modify or delete existing licenses or devices.
