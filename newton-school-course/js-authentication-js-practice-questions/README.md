## Problem Statement

Write a function authenticateUser(username, password, users) that validates the given username and password against a users object containing multiple user credentials. The function must return a promise that resolves or rejects exactly after 3 seconds as follows:

 * If the username exists in the users object and the password matches:

 After 3 seconds, resolve the promise with the message: "Login successful for user: username" (in place of username provide the username variable).

 * If the username does not exist or the password is incorrect:

 After 3 seconds, reject the promise with the message: "Authentication failed. Invalid username or password.".

 * The array of users are already given.

Below is an example user object

const users = {

 "admin": "password",

 "user1": "password1",

 "user2": "password2",

 "user3": "password3",

 "user4": "password4",

}

function authenticateUser(username, password, users)
{
return new Promise((res,rej)=>{
    setTimeout(()=>{
        if(users[username] && users[username]===password){
            res("Login successful for user: username")
        }else{
            rej("Authentication failed. Invalid username or password.")
        }

    },3000)

})
}
