## Problem Statement

You are maintaining a characters collection for the Doraemon universe. Each character can have multiple gadgets. Use embedded documents to store the gadgets a character owns.

Tasks:

1. Insert the following character document:

 "name": "Doraemon",

 "type": "Robot Cat",

 "gadgets": 

 "gadget_name": "Take-copter", "level": 5 ,

 "gadget_name": "Anywhere Door", "level": 4 

 

2. Write a query to find all characters who have the gadget Anywhere Door.

3. Write a query to increase the level of the Take-copter gadget by 1.

## Solution

```js
// 1. Insert the Doraemon document with embedded gadget subdocuments
db.characters.insertOne({
  name: "Doraemon",
  type: "Robot Cat",
  gadgets: [
    { gadget_name: "Take-copter", level: 5 },
    { gadget_name: "Anywhere Door", level: 4 }
  ]
});

// 2. Find all characters who have the gadget "Anywhere Door"
db.characters.find({
  "gadgets.gadget_name": "Anywhere Door"
});

// 3. Increase the level of the "Take-copter" gadget by 1
db.characters.updateOne(
  { "gadgets.gadget_name": "Take-copter" },
  { $inc: { "gadgets.$.level": 1 } }
);
```
