## Problem Statement

You are given a MongoDB collection named employees. Each document has the following structure:

{
 "name": String,
 "experience": Number, // years of experience
 "salary": Number // monthly salary
}

Write a MongoDB update query to perform the following operations on all employees:

 * If an employee has more than 2 years of experience, update it to 2 using the appropriate operator.

 * Increase the salary of all employees by 10% (i.e., multiply it by 1.1).

After updating, fetch only the name, experience, and salary fields for all employees.

## Solution

```js
db.employees.updateMany(
  {},
  [
    {
      $set: {
        experience: { $min: ["$experience", 2] },
        salary: { $multiply: ["$salary", 1.1] }
      }
    }
  ]
);

db.employees.find(
  {},
  {
    _id: 0,
    name: 1,
    experience: 1,
    salary: 1
  }
);
```
