## Problem Statement

Implement the given JavaScript function that takes a 2D array (an array of arrays) as input and returns a new 2D array where each element is doubled.

 
Constraints:

 You must not use loops (for, while, do while, for in, for of).

 Instead, use array methods such as .map(), .filter(), .reduce(), or .forEach().

### Input
A 2D array of numbers

### Output
2D array of numbers where each number is doubled as compared to input array

### Example
Input:
[[1,2,3],[4,5,6],[7,8,9]]

Output:
[ [ 2, 4, 6 ], [ 8, 10, 12 ], [ 14, 16, 18 ] ]

## Solution

```js
function doubleArray(arr) {
    let ans = arr.map((res)=>res.map((res)=> res*2))
    return ans

}
```
