Write a MongoDB aggregation query to calculate the average price of products for each category.

Your output should show:

 category

 * averagePrice

 * Sort by Category Name

## Solution

```js
db.products.aggregate([
  {
    $group: {
      _id: "$category",
      averagePrice: { $avg: "$price" }
    }
  },
  {
    $project: {
      _id: 0,
      category: "$_id",
      averagePrice: 1
    }
  },
  {
    $sort: {
      category: 1
    }
  }
]);
```
