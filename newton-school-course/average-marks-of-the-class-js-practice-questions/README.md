## Problem Statement

You are given an array of student objects, where each object represents a student and contains:

 * name: the student&rsquo;s name

 * marks: an array of 5 subject marks, each out of 10

Complete the JavaScript Function filterStudents to determine whether each student passes or fails based on the following rule:

 * If the average of the 5 subjects marks is greater than or equal to 35, the student Passes

 * Otherwise, the student Fails

Add the students who passed the exam in the given users array and return it.

### Input
An array of student details. Each student will be in the form of an object (Example of a user detail { name: "Rahul", marks: [40, 38, 42, 30, 35] } )

### Output
Print an array of student names who passed the exam.

### Example
Sample Input1:
[
 { name: "Rahul", marks: [40, 38, 42, 30, 35] },
 { name: "Aisha", marks: [25, 30, 20, 28, 22] },
 { name: "Ken", marks: [45, 50, 40, 38, 42] }
]

Sample Output1
['Rahul','Ken']

## Solution

```js
let users=[]; // Add all the students with average value >35 in this array.


function filterStudents(studentList) {
    studentList.filter((student)=>{
        let sum=student.marks.reduce((acc,mark)=> acc+mark,0)
        let avg = sum/student.marks.length
        if(avg>=35){
            users.push(student.name)

        }
    })
    return users
   
}
```
