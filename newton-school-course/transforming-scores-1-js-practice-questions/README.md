## Problem Statement

You are given an array of numerical scores and 2 callback functions named modifier1 and modifier2 need to implement the function processScores. This function applies two callback functions to modify the scores.

Each callback function should be applied to every element in the scores array, transforming them according to the provided logic.

### Input
First line of input is an array of numerical scores.
A series 2 of callback functions, each written on a new line in a compact single-line format.

### Output
a modified array after subjecting each element to given callback functions

### Example
Input:
[50, 75, 90, 100]
function(score) { return score + 5; }
function(score) { return score * 2; } 

Output:
[ 110, 160, 190, 210 ]

Explanation:
Initial array: [50, 75, 90, 100]
Step 1: Add 5 to each element → [55, 80, 95, 105]
Step 2: Multiply each element by 2 → [110, 160, 190, 210]
Final output: [110, 160, 190, 210]

## Solution

```js
function processScores(scores, modifier1, modifier2) {
    return scores.map(score => modifier2(modifier1(score)));
}
```
