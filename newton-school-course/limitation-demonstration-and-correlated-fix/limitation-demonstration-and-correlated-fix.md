## Problem Statement

Scenario: The branch manager wants to know which accounts perform above average within their own branch &mdash; not compared to the bank as a whole. A non-correlated subquery has already been written but only measures against the global average. Your task is to demonstrate its limitation and fix it.

Tasks:

1. Write a query that returns the account holder, branch, and balance for all accounts whose balance is greater than the average balance of their own branch. Use a correlated subquery to calculate the branch-specific average for each account.

### Output
 account_holder | branch | balance 
----------------+-----------+-----------
 Priya Mehta | Bangalore | 128000.00

(2 rows)

## Solution

```js
SELECT 
    account_holder, 
    branch, 
    balance
FROM 
    accounts a1
WHERE 
    balance > (
        SELECT AVG(balance) 
        FROM accounts a2 
        WHERE a2.branch = a1.branch
    );
```
