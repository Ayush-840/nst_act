## Problem Statement

You are given an undirected graph with n vertices and m edges. Your task is to return all the connected components of the graph.

### Input
User Task
This is a functional problem. You don’t have to take any input. You are required to complete the function connectedComponents() that takes two parameters:

* an integer n — the number of vertices, and

* a 2D list of edges — where each edge contains two integers representing an undirected edge between two vertices.

Custom Input
The first line contains two integers, n and m, representing the number of vertices and the number of edges respectively.

The next m lines each contain two integers u and v, denoting an undirected edge between vertex u and vertex v.

### Output
Return a list of connected components in the graph. Each connected component should be represented as a list of vertices. The components and the vertices within each component can be in any order.

### Example
Input:
7 4
0 1
2 3
3 4
5 6

Output:
[ [0, 1], [2, 3, 4], [5, 6] ]

Explanation:

The graph has 7 vertices numbered from 0 to 6.
The given edges connect the following vertices:

* 0 and 1 form one connected component.

* 2, 3, and 4 are connected through edges (2–3) and (3–4), forming another component.

* 5 and 6 form the third connected component.

## Solution

```py
def connectedComponents(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    visited = [False] * n
    ans = []
    def dfs(node, component):
        visited[node] = True
        component.append(node)
        for neigh in adj[node]:
            if not visited[neigh]:
                dfs(neigh, component)
    for i in range(n):
        if not visited[i]:
            component = []
            dfs(i, component)
            ans.append(component)

    return ans
```
