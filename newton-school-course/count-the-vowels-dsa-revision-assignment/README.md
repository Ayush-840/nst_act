## Problem Statement

You are given a string S that contains only lowercase English letters.

Your task is to write a Python program that counts how many vowels appear in the string.

The vowels to consider are: a, e, i, o, and u.

### Input
The first and only line of input contains the string S.

### Output
Print an integer - the count of vowels in the given string.

### Example
Input
newtonschool
Output
4
Explanation
The vowels in "newtonschool" are: e, o, o, o
Total = 4 vowels

Input
python
Output
1
Explanation
The only vowel in "python" is o

## Solution

```js
# Your code here
s = input().strip()
vowels = set("aeiou")
count = sum(1 for char in s if char in vowels)
print(count)
```
