## Problem Statement

Newton Bank stores customer details and account details in separate tables.

Write an SQL query to display the name of each customer along with their account type and account balance. Only customers who own an account should appear in the result.

Sort the output by customer_name in ascending order.

## Solution

```js
SELECT 
    c.customer_name,
    a.account_type,
    a.balance
FROM customers c
JOIN accounts a ON c.customer_id = a.customer_id
ORDER BY c.customer_name ASC;
```
