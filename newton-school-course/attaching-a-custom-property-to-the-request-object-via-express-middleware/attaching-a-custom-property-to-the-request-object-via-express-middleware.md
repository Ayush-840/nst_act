## Problem Statement

You are building an Express.js application where you need to track when each request was received by the server.

Write a middleware function using app.use() that intercepts every incoming request and attaches a custom property called receivedAt to the req object. This property should hold the timestamp (in milliseconds) at the time the request is received, using Date.now().

Requirements:

 * The middleware must be registered globally using app.use() so it applies to all routes.

 * It must attach req.receivedAt with the value of Date.now().

 * It must call next() to pass control to the next middleware/route handler.

 * A GET /ping route must respond with a JSON object: { receivedAt: &lt;timestamp&gt; } &mdash; reading the value from req.receivedAt.

## Solution

```js
const express = require('express');
const app = express();
app.use((req, res, next) => {
  req.receivedAt = Date.now();
  next();
});
app.get('/ping', (req, res) => {
  res.json({ receivedAt: req.receivedAt });
});
module.exports = app;
```
