## Problem Statement

You are given a sorted array of integers of size &lt;inlineMath&gt;n&lt;/inlineMath&gt; and a target value &lt;inlineMath&gt;x&lt;/inlineMath&gt;.

Your task is to find the index of the first occurrence of &lt;inlineMath&gt;x&lt;/inlineMath&gt; in the array.

If the target value does not exist in the array, return &lt;inlineMath&gt;-1&lt;/inlineMath&gt;.

The array is sorted in non-decreasing order.

Note: Since the test cases are executed multiple times, using a linear search leads to a Time Limit Exceeded (TLE) error. Therefore, the problem must be solved using an O(log n) time complexity approach.

### Input

The second line contains n integers forming the array nums = [a_1, a_2, \ldots, a_n].

### Output
For each test case, return a single integer — the index of the first occurrence of target, or -1 if it is not present.

### Example

Explanation

Test Case 1:
Array: [1, 2, 3, 3, 5], target = 3
The first occurrence of 3 is at index 2.

Test Case 2:
Array: [2, 4, 6, 8], target = 10
The target does not exist in the array, so the output is -1.

## Solution

```py
def FindFirst(n, nums, target):
    low = 0
    high = n - 1
    ans = -1

    while low <= high:
        mid = (low + high) // 2

        if nums[mid] == target:
            ans = mid
            high = mid - 1  # Keep searching on the left for the first occurrence
        elif nums[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return ans
```
