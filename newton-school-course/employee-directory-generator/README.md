## Problem Statement

HR wants to generate a clean employee directory. Names may have inconsistent formatting and need standardised display names and short-form employee codes built from their data.

Tasks:

1. Build a display_name column that formats names as "Lastname, Firstname" (e.g., &#39;Sharma, Rohit&#39;). Use CONCAT().

2. Show an emp_code column by combining the first 3 characters of the last name (uppercase) with the emp_id. Example: &#39;SHA101&#39;. Use SUBSTRING() and CONCAT().

3. Order by last name and display the corresponding department name.

UPPER(SUBSTRING(last_name, 1, 3)) || emp_id  as emp_code,
department from employees
order by last_name;
