## Problem Statement

Akash runs a small company and stores data in two collections:

employees:

[

 { "_id": 1, "name": "Alice", "department_id": 101 },

 { "_id": 2, "name": "Bob", "department_id": 102 },

 { "_id": 3, "name": "Charlie", "department_id": 101 }

]

departments:

[

 { "_id": 101, "department_name": "Sales" },

 { "_id": 102, "department_name": "Engineering" }

]

Akash wants to join these two collections so that each employee record also shows the department_name they belong to.

Write a MongoDB aggregation query using $lookup to get a list of employees with their department names in the following format:

[

 { name: &#39;Alice&#39;, department_name: &#39;Sales&#39; },

 { name: &#39;Bob&#39;, department_name: &#39;Engineering&#39; },

 { name: &#39;Charlie&#39;, department_name: &#39;Sales&#39; },

]

 

### Output
[
 { name: 'Alice', department_name: 'Sales' },
 { name: 'Bob', department_name: 'Engineering' },
 { name: 'Charlie', department_name: 'Sales' },
 { name: 'David', department_name: 'Marketing' }
]

## Solution

```js
db.employees.aggregate([
  {
    $lookup: {
      from: "departments",
      localField: "department_id",
      foreignField: "_id",
      as: "department"
    }
  },
  {
    $unwind: "$department"
  },
  {
    $project: {
      _id: 0,
      name: 1,
      department_name: "$department.department_name"
    }
  }
]);
```
