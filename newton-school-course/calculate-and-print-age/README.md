## Problem Statement

Write a Python program that takes two integers as input: the birth year and the current year.

Your task is to calculate the age by subtracting the birth year from the current year, and print the result.

### Input
The first line of input contains a single integer, the birth year.
The second line also contains a single integer, the current year.

### Output
Print an integer, the calculated age.

### Example
Input
2000
2024
Output
24
Explanation
Brith Year = 2000
Current Year = 2024
Age = 2024 - 2000 = 24

Input
2006
2025
Output
19
Explanation
Brith Year = 2006
Current Year = 2025
Age = 2025 - 2006 = 19

## Solution

```js
birth=int(input())
current=int(input())
age=current-birth
print(age)
```
