## Problem Statement

Write a program that takes the color of the traffic signal as input and displays the corresponding message.

A traffic signal can be Red, Yellow, or Green. Based on the signal color, you need to output the corresponding action:

&lt;b&gt;"Red" &rarr; "Stop"&lt;/b&gt;

&lt;b&gt;"Yellow" &rarr; "Ready"&lt;/b&gt;

&lt;b&gt;"Green" &rarr; "Go"&lt;/b&gt;

&lt;b&gt;For any other Color &rarr; "Invalid Color"&lt;/b&gt;

Note:

Since this is a Functional Problem, you do not need to take any input, just &lt;b&gt;print the corresponding action&lt;/b&gt; for Red, Yellow and Green traffic signal &lt;b&gt;otherwise print "Invalid Color"&lt;/b&gt; 

### Input
The first line contains the traffic signal color (e.g., "Red", "Green", or "Yellow").

### Output
A string representing the corresponding action based on the traffic signal color:
