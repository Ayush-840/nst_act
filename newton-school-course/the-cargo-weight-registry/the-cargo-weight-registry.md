## Problem Statement

A logistics company manages cargo shipments arriving at a central warehouse. Each shipment is represented by a pair of integers [arrivalTime, cargoWeight], where arrivalTime represents the time at which the shipment arrives and cargoWeight represents the weight of the cargo in kilograms.

The warehouse manager wants to arrange the shipments based on their cargo weights so that lighter shipments are processed first.

You are given a 2D array of size N*2, where each row represents one shipment. Your goal is to sort the array in ascending order based on the second element of each row (cargoWeight). If two shipments have the same cargo weight, either order is acceptable.

### Input
User Task

Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function cargoWeightRegistry(), which takes an integer N and a 2D array shipments as its parameters and returns a 2D array containing the shipments sorted in ascending order of cargoWeight.

Custom Input

There are two lines of input:

The first line of input contains an integer N representing the number of shipments.

The second line of input contains a 2D array of N rows and 2 columns, where each row contains two space-separated integers arrivalTime and cargoWeight, representing one shipment.

### Output
Return a 2D array containing the shipments sorted in ascending order of cargoWeight.

Each row of the returned array should contain two integers: arrivalTime and cargoWeight.

If multiple shipments have the same cargoWeight, their relative order can be arbitrary.
