## Problem Statement

A bank stores the daily balance of customer accounts.
The manager wants to compare each day&#39;s balance with the next recorded balance to understand upcoming balance changes.

ACCOUNT_BALANCES

+------------+--------------+---------+
| account_id | balance_date | balance |
+------------+--------------+---------+
| 101 | 2026-01-01 | 50000 |
| 101 | 2026-01-02 | 52000 |
| 101 | 2026-01-03 | 51000 |
| 101 | 2026-01-04 | 55000 |
+------------+--------------+---------+

Write an SQL query to display:

 account_id

 balance_date

 current_balance

 next_balance using the LEAD() window function for the same account_id

 balance_difference calculated as next_balance - current_balance

Order the final output by account_id and balance_date.

101 | 2026-01-03 | 51000 | 55000 | 4000

(5 rows)

## Solution

```js
SELECT 
    account_id,
    balance_date,
    balance AS current_balance,
    LEAD(balance) OVER (
        PARTITION BY account_id 
        ORDER BY balance_date
    ) AS next_balance,
    LEAD(balance) OVER (
        PARTITION BY account_id 
        ORDER BY balance_date
    ) - balance AS balance_difference
FROM 
    ACCOUNT_BALANCES
ORDER BY 
    account_id,
    balance_date;
```
