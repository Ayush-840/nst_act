## Problem Statement

Rainboy has a circular drum with circumference C and a thread of length X.
He wraps the thread around the drum, where each full rotation consumes exactly C units.
After making as many full rotations as possible, some length of the thread may remain.

Your task is to find and print the remaining length of the thread.

### Input
A single line containing two integers C (circumference of the drum) and X (length of the thread).

### Output
Print a single integer, the remaining length of the thread after Rainboy completes wrapping.

### Example
Input 
12 29 

Output 
5 

Explanation 
If we rotate the thread around the drum 2 times, the remaining thread length will be 5.

## Solution

```js
C,X=map(int,input().split())
remaininglength = X%C

print(remaininglength)
```
