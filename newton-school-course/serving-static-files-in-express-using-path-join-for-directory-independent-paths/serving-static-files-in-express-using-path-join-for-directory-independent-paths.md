## Problem Statement

Your frontend engineer has handed off their production build. The compiled files live inside a folder named client/build, located at the root of the project (a sibling of the src folder your server code lives in).

Write the Express server code (src/index.js) that:

 * Serves the contents of client/build as static files.

 * Mounts them under the URL path prefix /client (e.g., a file client/build/logo.png should be reachable at GET /client/logo.png).

 * Resolves the folder path using Node&#39;s path module (path.join with __dirname) so the server works correctly no matter which directory Node is started from &mdash; do not hardcode an absolute path as a string.

Export the app instance (do not call .listen()).

## Solution

```js
const app = express();
// 1. Import the inventory router from the routes folder
const inventoryRouter = require('./routes/inventory.router');

app.use(express.json());
// 3. Mount the router under the /api/inventory prefix
app.use('/api/inventory', inventoryRouter);
if (require.main === module) {
```
