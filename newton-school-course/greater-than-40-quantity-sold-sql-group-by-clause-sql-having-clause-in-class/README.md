## Problem Statement

At ShopNext, the operations team wants to monitor which product categories are driving the highest number of unit sales. All product sales are stored in the SalesData table.

Your task is to write an SQL query that:

 * Calculates the total quantity sold per category

 * Returns only those categories where the total quantity sold is greater than 40

## Solution

```js
select category, sum(quantity_sold) as total_quantity from SalesData
group by category;
```
