## Problem Statement

You are given a list of integers and a specific target value.

Your task is to determine how many times the target value appears in the list and print the count.

Note: count() function is not allowed

### Input
The first line of input consist of space-separated integers, representing elements of the list.
The second and final line of input contains a single integer target.

### Output
Print the single integer, representing the count of target in the given list.

### Example
Input
1 3 2 1 3 5 9 1
1
Output
3
Explanation
The target value 1 appears thrice in the given list.

Input
1 3 2 1 3 5 9 1
6
Output
0
Explanation
The target value 6 is not present in the given list.

## Solution

```js
// ─── 2 ───
# Your code here
l=list(map(int,input().split()))
target=int(input())
c=0
for i in l:
    if i==target:
        c+=1
print(c)
```
