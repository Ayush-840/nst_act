## Problem Statement

A valid IP address consists of exactly four integers separated by single dots.

Each integer must be between 0 and 255 (inclusive) and cannot contain leading zeros.

For example:

 * Valid: "0.1.2.201", "192.168.1.1"

 * Invalid: "0.011.255.245", "192.168.1.312", "192.168@1.1"

Given a string s containing only digits, insert dots into s to form all possible valid IP addresses.

 * You are not allowed to reorder or remove digits.

 * Return all possible valid IP addresses in any order.

 

### Input
The first line contains an integer t — the number of test cases.
Each test case contains:
* A string s consisting only of digits.

### Output
For each test case, return a list of all valid IP addresses.

If no valid IP address can be formed, return an empty list. The driver code will print [].

The driver code will also sort the IP addresses before printing.

### Example
Input
3
25525511135
0000
101023

Output
255.255.11.135
255.255.111.35
0.0.0.0
1.0.10.23
1.0.102.3
10.1.0.23
10.10.2.3
101.0.2.3

Explanation
* For the first test case, "25525511135" can be split as "255.255.11.135" or "255.255.111.35".

* For the second test case, "0000" can only be split as "0.0.0.0".

* For the third test case, "101023" has five valid splits: "1.0.10.23", "1.0.102.3", "10.1.0.23", "10.10.2.3", and "101.0.2.3".

## Solution

```py
class Solution(object):
    def restoreIpAddresses(self, s):
        """
        :type s: str
        :rtype: List[str]
        """
        ans=[]
        path=[]
        def back(i):
            if len(path)==4:
                if i==len(s):
                    ans.append(".".join(path))
                    return
            for j in range(i, min(i + 3, len(s))):
                part = s[i:j + 1]
                if len(part) > 1 and part[0] == "0":
                    continue
                if int(part) > 255:
                    continue
                path.append(part)
                back(j + 1)
                path.pop()
        back(0)
        return ans
```
