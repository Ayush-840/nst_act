## Problem Statement

Given a string s, your task is to find the total number of unique characters in a string.

### Input
The first line of the input contains a string s, 
Note: s can also contain white spaces.

### Output
Print the total number of unique characters.

### Example

Sample Input 1:
Newton School

Sample Output 1:
11

Explanation: The string contains 13 characters (including the space): N, e, w, t, o, n, , S, c, h, o, o, l. But since the we need is unique characters, then only 1 out of 3 o's are counted, so the total count is 11.
