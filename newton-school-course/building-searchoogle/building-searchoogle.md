When the server receives a GET request to /search:

 * Read articles.txt asynchronously using fs.readFile().

 * Search for all lines containing the keyword in a case-insensitive manner.

Error Handling

If articles.txt cannot be read, return:

 * Status Code: 500 Internal Server Error

 * Response Body: Unable to read articles

For any other route, return:

 * Status Code: 404 Not Found

 * Response Body: Not Found
