## Problem Statement

Build a simple Theme Preference Manager using Express.js that allows users to choose a preferred theme (light or dark).

The application should remember the user&#39;s selected theme using a cookie that expires after one hour.

Requirements:

 

1. Set Theme

Endpoint: GET /theme/:name

 * 
 Accept the theme name as a URL parameter.

 

 * 
 Store the selected theme in a cookie named theme.

 

 * 
 Set the cookie to expire after 1 hour (3,600,000 milliseconds).

 

 * 
 Return the following JSON response:

 
{
 "message": "Theme updated successfully",
 "theme": name
}
 

 

2. Get Theme

Endpoint: GET /theme

 * 
 Read the theme preference from the user&#39;s cookies.

 

 * 
 If a theme cookie exists, return the saved theme.

 

 * 
 If no theme cookie exists, return light as the default theme.

 
{
 "theme": "light"
}

## Solution

```js
const PORT = process.env.PORT || 3000;
app.use(cookieParser());
// 1. Set Theme: GET /theme/:name
app.get('/theme/:name', (req, res) => {
  const { name } = req.params;
  // Store in a cookie named 'theme' expiring in 1 hour (3,600,000 ms)
  res.cookie('theme', name, {
    maxAge: 3600000,
    httpOnly: true,
    sameSite: 'lax',
  });
  return res.status(200).json({
    message: 'Theme updated successfully',
    theme: name,
  });
});
// 2. Get Theme: GET /theme
app.get('/theme', (req, res) => {
  const savedTheme = req.cookies?.theme;
  return res.status(200).json({
    theme: savedTheme || 'light',
  });
});
app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});
```
