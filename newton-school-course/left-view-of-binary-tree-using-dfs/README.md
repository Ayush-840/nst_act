## Problem Statement

Given the root node of a binary tree, your task is find its left view.

Note: The left view of a binary tree is determined by the nodes visible when you look at the tree from the left side. This means that for each level in the tree, the left view includes only the first (or leftmost) node encountered.

### Input
User Task
Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function left_view(), which takes the root node as its parameter.

Custom Input
The first line of input contains a positive integer N, representing the number of nodes in the tree.
The next line consists of space-separated integers denoting the level order traversal of the tree, where non-negative values represent node values, and -1 indicates a null node.
Note: Once a node is marked as -1, no further information about its children is provided.

Constraints
1 \le N \le 10^3
0 \le Node.val \le 10^4

### Output
Return an array representing the left view of the binary tree.
