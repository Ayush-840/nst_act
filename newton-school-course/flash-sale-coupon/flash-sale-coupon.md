## Problem Statement

An e-commerce platform launches a flash sale when its Node.js server starts.

Customers who visit http://localhost:3000 within the first 20 seconds of the server starting should receive:

 * Status Code: 200 OK

 * Response Body:
 
Congratulations! Your coupon code is FLASH20
 

Customers who visit after 20 seconds should receive:

 * Status Code: 408 Request Timeout

 * Response Body:
 
Sorry! The flash sale has ended.
 

Note: To determine whether the flash sale is still active, calculate the elapsed time since the server started using:

const elapsedTime = Date.now() - serverStartTime;

Create a Node.js HTTP server using the built-in http module to implement this behavior.

## Solution

```js
require('dotenv').config();
const http = require('http');
const PORT = process.env.PORT || 3000;
const server = http.createServer((req, res) => {
  if (req.url === '/') {
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end('Homepage');
  } else {
    res.writeHead(404, { 'Content-Type': 'text/plain' });
    res.end('This page does not exist');
  }
});
server.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});
module.exports = server;
```
