## Problem Statement

Given a set of distinct positive integers nums, return the largest subset answer such that every pair (answer[i], answer[j]) of elements in this subset satisfies:

 * answer[i] % answer[j] == 0, or

 * answer[j] % answer[i] == 0

If there are multiple solutions, return any of them.

### Input
User Task
Since this is a functional problem, you don't have to input anything. You just need to complete the largestDivisibleSubset() function that takes an array nums as the parameter and returns the largest subset that satisfies the given conditions.

Custom Input
The first line of the input contains a single integer n, representing the size of the array nums.
The second line of the input contains n space separated integers representing elements of the array nums.

### Output
Return the largest subset that satisfies the given conditions.

### Example

def largestDivisibleSubset(nums):

    nums.sort(reverse = True)
    n = len(nums)
    dp = [1] * n 
    ans = 1
    prev = [-1] * n
    idx = -1
    for i in range(1, n):
        for j in range(i):
            if nums[j] % nums[i] == 0 and dp[i] < dp[j] + 1:
                dp[i] = dp[j] + 1
                prev[i] = j
        
        if dp[i] > ans:
            ans = dp[i]
            idx = i
    
    res = [0] * ans
    i = 0
    while idx >= 0:
        res[i] = nums[idx]
        idx = prev[idx]
        i += 1
    return res
