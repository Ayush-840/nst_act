## Problem Statement

A company named BookFlix maintains a collection booksales that stores monthly sales data for different books.

[

 { "_id": 1, "title": "MongoDB Basics", "author": "John Doe", "copies_sold": 1200, "month": "2025-01" },

 { "_id": 2, "title": "Advanced Node.js", "author": "Jane Smith", "copies_sold": 950, "month": "2025-01" },

 { "_id": 3, "title": "JavaScript in Depth", "author": "John Doe", "copies_sold": 1800, "month": "2025-01" },

 { "_id": 4, "title": "Mastering Python", "author": "Emily Clark", "copies_sold": 2000, "month": "2025-01" },

 { "_id": 5, "title": "Data Structures with C++", "author": "Alex Ray", "copies_sold": 700, "month": "2025-01" }

]

Sort the books by copies_sold in descending order, then by title in ascending order if copies are equal, and return only title, author, and copies_sold.

 

### Example
[
 { "title": "Mastering Python", "author": "Emily Clark", "copies_sold": 2000 },
 { "title": "JavaScript in Depth", "author": "John Doe", "copies_sold": 1800 },
 { "title": "MongoDB Basics", "author": "John Doe", "copies_sold": 1200 },
 { "title": "Advanced Node.js", "author": "Jane Smith", "copies_sold": 950 },
 { "title": "Data Structures with C++", "author": "Alex Ray", "copies_sold": 700 }
]

## Solution

```js
db.booksales.aggregate([
  {
    $sort: {
      copies_sold: -1,
      title: 1
    }
  },
  {
    $project: {
      _id: 0,
      title: 1,
      author: 1,
      copies_sold: 1
    }
  }
]);
```
