## Problem Statement

You are given an integer n. Your task is to generate and print all valid passwords of length n using characters from the following set:

chars = aeiou1234@

A character may be used any number of times in a password.

A password is considered valid if it satisfies both of the following conditions:

 No two consecutive characters in the password are the same.

 The password contains at most two numeric characters (1, 2, 3, or 4).

Print all possible valid passwords of length n.

 

For n = 4:

Some Valid passwords: a1e2, aeiu, 1a2e, e4o1, @a1e, oi4@

Some Invalid passwords: aa1u (repeated a), 1a23 (three digits), e11@ (repeated 1), o44o (repeated 4), 12a3 (three digits), ee1o (repeated e)

### Input
A single integer n, representing the length of each password.

### Output
Print every possible password of length n. (you can print in any order)

Print each password on a new line.
