## Problem Statement

Akash now wants more detailed insights into salaries across departments.

Write a MongoDB aggregation query to:

 
 Group employees by their department.

 

 
 Calculate the total salary, average salary, and number of employees in each department.

 

 
 Only include departments where the total salary exceeds 3,00,000.

 

 
 Return the results sorted by total salary in descending order.

 

employees Collection:

[

 { "_id": 1, "name": "Alice", "department_id": 101, "salary": 45000 },

 { "_id": 2, "name": "Bob", "department_id": 102, "salary": 60000 },

 { "_id": 3, "name": "Charlie", "department_id": 102, "salary": 55000 },

 { "_id": 4, "name": "David", "department_id": 101, "salary": 50000 },

]

departments Collection:

[

 { "_id": 101, "department_name": "HR" },

 { "_id": 102, "department_name": "IT" },

 { "_id": 103, "department_name": "Finance" },

 { "_id": 104, "department_name": "Marketing" }

]

 

### Output
[
 { "department": "IT", "total_salary": 487000, "average_salary": 69571.43, "employee_count": 7 },
 { "department": "Finance", "total_salary": 446000, "average_salary": 74333.33, "employee_count": 6 }
]

## Solution

```js
db.employees.aggregate([
  {
    $lookup: {
      from: "departments",
      localField: "department_id",
      foreignField: "_id",
      as: "department_info"
    }
  },
  {
    $unwind: "$department_info"
  },
  {
    $group: {
      _id: "$department_info.department_name",
      total_salary: { $sum: "$salary" },
      average_salary: { $avg: "$salary" },
      employee_count: { $sum: 1 }
    }
  },
  {
    $match: {
      total_salary: { $gt: 300000 }
    }
  },
  {
    $project: {
      _id: 0,
      department: "$_id",
      total_salary: 1,
      average_salary: { $round: ["$average_salary", 2] },
      employee_count: 1
    }
  },
  {
    $sort: {
      total_salary: -1
    }
  }
]);
```
