## Problem Statement

Write a program to convert a temperature value from Celsius to Fahrenheit using the formula:

&lt;inlineMath&gt;Fahrenheit = (Celsius * 9 / 5​) + 32&lt;/inlineMath&gt;.

Note: Use the round() function to round numbers to 1 decimal place.

### Input
A single line containing a temperature in Celsius (as a float).

### Output
Print the corresponding temperature in Fahrenheit (as a float) and round it to 1 decimal place using round().

### Example
Input
0
Output
32.0
Explanation
Input Celsius = 0
Fahrenheit = (0 × 9/5) + 32 = 0 + 32 = 32.0
So the output is 32.0.

## Solution

```js
Celsius=int(input())
Fahrenheit=Celsius*9/5 + 32

print(round(Fahrenheit,1))
```
