## Problem Statement

Given an integer array arr[], your task is to print the alternate elements of the array starting from the 0th index.

### Input
The first line of input contains an integer N, representing the number of elements in the array.
The second and final line of input contains N space-separated integers, representing the elements of the array.

Constraints
1 \le N \le 10^5
-10^5 \le arr[i] \le 10^5

### Output
Print the space separated elements representing the alternating elements of the given array.

### Example
Input
5
1 2 3 4 5
Output
1 3 5
Explanation
Starting from the 0th index, the alternating indices are: 0, 2, 4. And thus the elements are 1, 3, and 5.

## Solution

```py
# Your code here
import sys

def main():
    # Read all input from standard input
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    arr = input_data[1:n+1]
    
    # Select alternate elements starting from index 0
    alternate_elements = arr[::2]
    
    # Print space-separated elements
    print(*(alternate_elements))

if __name__ == "__main__":
    main()
```
