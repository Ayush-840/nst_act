Screen names are typed by each cinema, so IMAX may appear in any letter case.

What the job must do, in this order

 * Cancel empty shows. Shows before 20 March 2026 that sold fewer than 10 seats are cancelled. A show that sold exactly 10 runs. Shows already cancelled stay cancelled.

 * Refund. Every ticket of a cancelled show becomes refunded. Tickets of shows that still run are untouched.

 * Premium pricing. Raise base_price by 15 percent, rounded to 2 decimals, for IMAX screens only.

 * Reset counters. Set seats_sold to 0 for cancelled shows. Shows that still run keep their count.

 * Purge. Delete refunded tickets booked before 1 January 2026.

The job has exactly four logical errors. Every statement runs. Fix them without adding, removing or reordering statements.

UPDATE shows SET is_cancelled = true
WHERE show_on < DATE '2026-03-20' AND seats_sold < 10;
-- done

-- 2. refund every ticket of a cancelled show
UPDATE tickets SET status = 'refunded'
WHERE show_id IN (SELECT id FROM shows);

-- 3. premium screen price revision
UPDATE shows SET base_price = ROUND(base_price * 1.15, 2)
WHERE UPPER(screen) = 'IMAX';

-- 4. zero the seat counter of cancelled shows
UPDATE shows SET seats_sold = 0
WHERE is_cancelled = true;
-- done
