## Problem Statement

You are provided with a database schema containing two tables: Employees and Departments. Your task is to create an SQL query using a Common Table Expression (CTE) that retrieves the average salary of each department along with the total number of employees in that department. The result should display the department name, average salary, and the count of employees for each department. Order the result by average_salary in descending order.

## Solution

```js
with AvgSalaryPerDept as (
    select 
        d.department_id, 
        d.department_name, 
        avg(e.salary) as average_salary,
        count(e.department_id) as employee_count 
    from departments d 
    join employees e
    using (department_id) 
    group by d.department_id, d.department_name
)
select aspd.department_name, aspd.average_salary, aspd.employee_count 
from AvgSalaryPerDept as aspd 
order by aspd.average_salary desc;
```
