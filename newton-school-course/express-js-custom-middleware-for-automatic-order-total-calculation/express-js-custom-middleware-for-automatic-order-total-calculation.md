## Problem Statement

You are building the backend for a wholesale inventory management system. Your task is to create a custom Express.js middleware that automatically pre-calculates order totals before the request reaches the route handler.

Requirements:

 * Create an Express.js app in src/index.js and export it as module.exports = app (do not call app.listen()).

 * Register express.json() to parse incoming JSON bodies.

 * Write a custom middleware function that:
 
 * Intercepts every incoming request using app.use() (global middleware)

 * Multiplies req.body.pricePerItem by req.body.quantity

 * Attaches the result to req.body.calculatedTotal

 * Then calls next() to pass control to the next middleware/route

 * You may assume pricePerItem and quantity will always be present and numeric in the request body.

 
 

 * Register a POST /orders route that responds with the entire req.body as a JSON response (status 200).

 * The middleware must run before the route handler so that calculatedTotal is always present in the response.

Example:

Request body:

{ "item": "Wheat Flour", "pricePerItem": 40, "quantity": 50 }

Expected response:

{ "item": "Wheat Flour", "pricePerItem": 40, "quantity": 50, "calculatedTotal": 2000 }
