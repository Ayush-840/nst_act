## Problem Statement

A company maintains employee performance scores. The HR department wants to generate a ranked list of employees based on their performance for appraisal discussions.
Unlike aggregate functions, the ranking should not collapse rows. Each employee should retain their record while receiving a unique row number.

EMPLOYEE_PERFORMANCE

+-------------+---------------+-------------------+
| employee_id | employee_name | performance_score |
+-------------+---------------+-------------------+
| 101 | Aarav | 92 |
| 102 | Diya | 88 |
| 103 | Vivaan | 95 |
| 104 | Ananya | 81 |
| 105 | Ishaan | 90 |
+-------------+---------------+-------------------+

Write SQL queries using the ROW_NUMBER() window function only (do not use LIMIT, TOP, or aggregate functions):

Assign a unique row number (rank_number) to each employee based on descending performance_score.

 

### Output
 employee_id | employee_name | performance_score | rank_number 
-------------+---------------+-------------------+-------------
 103 | Vivaan | 95 | 1
 101 | Aarav | 92 | 2
 105 | Ishaan | 90 | 3
 102 | Diya | 88 | 4
 104 | Ananya | 81 | 5
(5 rows)

## Solution

```js
select
employee_id,
employee_name,
performance_score,
ROW_NUMBER() over(order by performance_score desc) as rank_number
from EMPLOYEE_PERFORMANCE
```
