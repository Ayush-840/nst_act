## Problem Statement

The revenue team at SkyWings Airlines wants to understand how each flight route is performing. They store data in the Flights table, which tracks details like origin, destination, number of seats sold, and revenue per flight.
Your task is to write an SQL query that calculates:

 * total revenue as total_revenue

 * total seats sold as total_seats_sold

 * Group the data by both origin and destination

 * Display columns in this exact order: origin, destination, total_revenue, total_seats_sold

## Solution

```js
// ─── 1 ───
SELECT 
    origin,
    destination,
    SUM(revenue) AS total_revenue,
    SUM(seats_sold) AS total_seats_sold
FROM 
    Flights
GROUP BY 
    origin, 
    destination;
```
