## Problem Statement

Rahul runs a movie streaming platform. The movies collection stores ratings given by users:

[

 { "_id": 1, "title": "Inception", "genre": "Sci-Fi", "rating": 9.0, "release_year": 2010 },

 { "_id": 2, "title": "The Dark Knight", "genre": "Action", "rating": 9.1, "release_year": 2008 },

 { "_id": 3, "title": "Interstellar", "genre": "Sci-Fi", "rating": 8.6, "release_year": 2014 },

 { "_id": 4, "title": "Tenet", "genre": "Sci-Fi", "rating": 7.5, "release_year": 2020 },

 { "_id": 5, "title": "Dunkirk", "genre": "War", "rating": 7.9, "release_year": 2017 }

]

Filter movies belonging to the "Sci-Fi" genre, sort them by rating in descending order (and by release_year in descending order if ratings match), and return only title, rating, and release_year.

### Example
[
 { "title": "Inception", "rating": 9.0, "release_year": 2010 },
 { "title": "Interstellar", "rating": 8.6, "release_year": 2014 },
 { "title": "Tenet", "rating": 7.5, "release_year": 2020 }
]

## Solution

```js
db.movies.aggregate([
  {
    $match: {
      genre: "Sci-Fi"
    }
  },
  {
    $sort: {
      rating: -1,
      release_year: -1
    }
  },
  {
    $project: {
      _id: 0,
      title: 1,
      rating: 1,
      release_year: 1
    }
  }
]);
```
