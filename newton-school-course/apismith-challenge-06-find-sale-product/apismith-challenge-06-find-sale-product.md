## Problem Statement

An e-commerce platform manages a product database that stores details such as product name, price, category, and sale status.

Your task is to implement the function getSaleProducts(api, clothingType), which should:

 Fetch product data from the provided API.

 Filter the results to include only products that belong to the specified clothing type (e.g., "T-Shirt", "Jeans") and are currently on sale.

 Return a promise that resolves to an array of matching product names.

### Input
Space seperated strings representing an api (fetches movie data) & clothingType for which sale products need to be retrieved.

### Output
Return a promise that resolves to an array of matching product names. If no matching products are found, the promise should resolve to an empty array ([]).

### Example
Sample Input:
"https://api.test.com/data" T-Shirt

Sample Output:
["Casual T-Shirt", "Graphic T-Shirt", "Polo T-Shirt"]

Explanation:
These three are the names of products that belong to the "T-Shirt" category and are currently on sale.

// Your code here
async function getSaleProducts(api, clothingType) {
  try {
    const response = await fetch(api);

    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }

    const data = await response.json();
    const products = Array.isArray(data)
      ? data
      : Array.isArray(data.products)
        ? data.products
        : [];

    return products
      .filter(
        (product) =>
          product &&
          product.category === clothingType &&
          Boolean(product.onSale ?? product.isOnSale ?? product.sale)
      )
      .map((product) => product.name);
  } catch (error) {
    return [];
  }
}
