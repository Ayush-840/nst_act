## Problem Statement

You are given an API endpoint that fetches a JSON array of objects. Each object may contain a tags array of different lengths. Your task is to implement the function queryMaximumTags(api) that:

 * Fetches data from the given api endpoint.

 Returns a JavaScript Promise that resolves into an array of objects, where each object has the maximum number of tags among all objects in the dataset.

### Input
An API string

### Output
A JavaScript Promise that resolves into an array of objects, where each object has the maximum number of tags among all objects in the dataset.

## Solution

```js
// Your code here
function queryMaximumTags(api){
    return fetch(api).then((res)=> res.json())
    .then(data=>{
        const cnt=data.map(tag => tag.tags.length)
        const mxcnt=Math.max(...cnt)
        data.filter(res=>res.tags.length===mxcnt)

    })
}
```
