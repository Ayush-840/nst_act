## Problem Statement

You are provided with two variables, a and b. Without using any additional variables, your task is to swap the values of a and b.

Output the swapped values of a and b each on a separate new line using console.log().

NOTE: you can access the values by simply calling a and b.

### Input
The first line of input will contain two space-separated integers a and b (Given).

### Output
Output the swapped values of a and b in two separate lines.

### Example
Input: 
5 10

Output:
10
5

## Solution

```js
[a,b]=[b,a]
console.log(a)
console.log(b)
```
