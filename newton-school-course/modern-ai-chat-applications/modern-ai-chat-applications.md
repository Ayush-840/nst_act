## Problem Statement

Modern AI chat applications allow users to view their previous conversations through a Chat History page.

In this challenge, you will create a Node.js HTTP server that reads a saved chat history from a file and returns it to the client.

Create an HTTP server that exposes the following endpoint:

GET /history

When a client sends a request to this endpoint, your server should:

 * Read the contents of chat.txt.

 * Return the complete chat history as the response.

 * If chat.txt cannot be found or cannot be read, respond with an appropriate error message.

Example chat.txt

User: Hello
AI: Hi! How can I help you today?

User: What is Node.js?
AI: Node.js is a JavaScript runtime built on Chrome's V8 engine.

User: Thank you
AI: You're welcome!

Example Request

GET /history

Expected Response

Status Code: 200 OK

User: Hello

Error Case

If chat.txt cannot be found or cannot be read:

Status Code: 500 Internal Server Error

Unable to load chat history
