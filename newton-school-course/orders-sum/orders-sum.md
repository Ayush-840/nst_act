## Problem Statement

Sample Collection: orders

[

 { "_id": 1, "customer": "Riya", "amount": 1200, "status": "Delivered" },

 { "_id": 2, "customer": "Riya", "amount": 800, "status": "Pending" },

 { "_id": 3, "customer": "Arjun","amount": 1500, "status": "Delivered" },

 { "_id": 4, "customer": "Diya", "amount": 600, "status": "Cancelled" }

]
Using MongoDB Aggregation Methods, write a query to calculate the following for each customer:

 Total amount spent

 Count of delivered orders

 * Maximum order amount

 * Sort the output by name of customer

### Example
 Sample Ouput
 {
 _id: 'Arjun',
 totalAmountSpent: 3100,
 deliveredCount: 2,
 maxOrderAmount: 1500
 }

## Solution

```js
db.orders.aggregate([
  {
    $group: {
      _id: "$customer",
      totalAmountSpent: { $sum: "$amount" },
      deliveredCount: {
        $sum: {
          $cond: [{ $eq: ["$status", "Delivered"] }, 1, 0]
        }
      },
      maxOrderAmount: { $max: "$amount" }
    }
  },
  {
    $sort: {
      _id: 1
    }
  }
]);
```
