## Problem Statement

Given a positive integer N, your task is to calculate the sum of the squares of all integers from 1 to N (inclusive).

In other words, you need to calculate the value of &lt;inlineMath&gt;\sum_{i=1}^{N} i^2&lt;/inlineMath&gt;.

### Input
The first and only line of input contains an integer N.

### Output
Print an integer representing the sum of the squares of all integers from 1 to N (inclusive).

### Example
Input
5
Output
55
Explanation
Sum of squares of number from 1 to 5 is:
12 + 22 + 32 + 42 + 52 = 1 + 4 + 9 + 16 + 25 = 55

Input
3
Output
14
Explanation
Sum of squares of number from 1 to 3 is:
12 + 22 + 32 = 1 + 4 + 9 = 14

## Solution

```js
# Your code here
N = int(input())
result = (N * (N + 1) * (2 * N + 1)) // 6
print(result)
```
