## Problem Statement

The students collection stores information about college students. Each document contains their name, year, and department. One day, the administration realised that a student named Riya, who is in the 3rd year and belongs to the Computer Science department, was mistakenly listed as being in the "3rd year" and should actually be in the 4th year.

Task:

Write a MongoDB query to update only the year of the student Riya from 3 to 4, but only if she is currently in the Computer Science department and listed as being in the 3rd year.

After updating, write a query to display Riya&rsquo;s updated record from the database to verify the update.

 

📄 Sample Document Schema:
 

{

 name: "Riya",

 year: 3,

 department: "Computer Science"

}

## Solution

```js
//query goes here

db.students.updateOne(
  {
    name: "Riya",
    year: 3,
    department: "Computer Science"
  },
  {
    $set: { year: 4 }
  }
);

db.students.find({
  name: "Riya",
  department: "Computer Science"
});
```
