## Problem Statement

An online shopping platform wants to safely update product stock after a customer places an order.

The system should reduce the stock quantity of a product and confirm the changes only if all operations are successful.

Write a PostgreSQL query to:

 * Start a transaction

 * Reduce the stock of the product Laptop by 1

 * Permanently save the changes

## Solution

```js
begin;
update products set stock=stock-1 where product_name='Laptop';
commit;
select*from products
```
