## Problem Statement

Given an integer array arr of size N. Your task is to compute the sum of the elements located at even indices.

Note: Arr follows 0-based indexing.

Note-2: This is a functional problem.

 

### Input
User Task
Since this is a functional problem, you do not need to take input. Your task is to complete the function even_sum() that takes an integer array arr as an input parameter.

Custom Input
The first line of input contains an integer N, representing the number of elements in the array.
The second and final line of input contains N space-separated integers, representing the elements of the array.

Constraints
1 \le N \le 10^5
-10^5 \le arr[i] \le 10^5

### Output
Return an integer, representing the sum of the elements located at even indices.

### Example
Input
5
32 17 0 3 7
Output
39
Explanation
Even-indexed elements (indices 0, 2, and 4) are 32, 0, and 7, which add up to 39.

Input
5
0 2 4 6 0
Output
4
Explanation
Even-indexed elements (indices 0, 2, and 4) are 0, 4, and 0, which add up to 4.

## Solution

```py
def even_sum(arr):
    return sum(arr[::2])
```
