## Problem Statement

Sometimes, an application needs to get data from more than one service. If these services are called one by one, the response takes more time. To make the response faster, start both asynchronous operations before waiting for their results.

Sometimes, one of the services may fail. Use try...catch to handle the error and return the correct error response instead of letting the application crash.

Task Requirements:

 * 
 Implement an HTTP GET route at the parameterized path /api/dashboard/:userId.

 

 * 
 Capture the incoming :userId parameter from the request parameters.

 

 * 
 Start both asynchronous functions without using Promise.all():

 
 * 
 getProfile(userId)

 

 * 
 getCreditScore(userId)

 

 
 

 * 
 Wait for both operations to finish successfully by awaiting each promise individually.

 

 * 
 Combine the data from both functions with the userId into one JSON object and return it using res.json().

 

 * 
 Include a try/catch safety layer. If either function fails (rejects), catch the error, set the HTTP response status header code to 500, and return this exact JSON body:

 
{ "error": "One or more external services failed." }

 Example 1 (Success Case):
