## Problem Statement

Sometimes, an application needs to get data from more than one service. If these services are called one by one, the response takes more time. To make the response faster, start both asynchronous operations before waiting for their results.

Sometimes, one of the services may fail. Use try...catch to handle the error and return the correct error response instead of letting the application crash.
