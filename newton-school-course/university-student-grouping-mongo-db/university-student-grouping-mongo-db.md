## Problem Statement

University stores students and their courses in separate collections.

students collection:

[

 { "_id": 1, "name": "Alice", "email": "alice@example.com" },

 { "_id": 2, "name": "Bob", "email": "bob@example.com" },

 { "_id": 3, "name": "Charlie", "email": "charlie@example.com" }

]

courses collection:

[

 { "_id": 101, "student_id": 1, "course_name": "Mathematics" },

 { "_id": 102, "student_id": 2, "course_name": "Physics" },

 { "_id": 103, "student_id": 1, "course_name": "Computer Science" },

 { "_id": 104, "student_id": 3, "course_name": "Chemistry" }

]

Write a MongoDB Aggregation Pipeline using $lookup to display each course along with the student&rsquo;s name and email.

 

### Output
{
 course_name: 'Mathematics',
 student_name: 'Alice',
 email: 'alice@example.com'
 },
 {
 course_name: 'Physics',
 student_name: 'Bob',
 email: 'bob@example.com'
 },

## Solution

```js
db.courses.aggregate([
  {
    $lookup: {
      from: "students",
      localField: "student_id",
      foreignField: "_id",
      as: "student_info"
    }
  },
  {
    $unwind: "$student_info"
  },
  {
    $project: {
      _id: 0,
      course_name: 1,
      student_name: "$student_info.name",
      email: "$student_info.email"
    }
  }
]);
```
