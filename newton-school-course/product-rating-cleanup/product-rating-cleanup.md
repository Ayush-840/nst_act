## Problem Statement

An e-commerce platform stores product ratings collected from two different systems. Some ratings were entered as negative values due to a data entry bug. The team needs to standardise all ratings and flag unusual ones.

Table schema:

CREATE TABLE products (
 product_id INT,
 product_name VARCHAR(100),
 raw_rating NUMERIC, -- may be negative due to bug
 system_b_avg NUMERIC -- benchmark rating
);

Products table:

+------------+--------------------+------------+--------------+
| product_id | product_name | raw_rating | system_b_avg |
+------------+--------------------+------------+--------------+
| 101 | Wireless Mouse | -4.76 | 4 |
| 102 | Mechanical Keyboard | 4.24 | 4.3 |
| 103 | Gaming Headset | -3.89 | 3 |
| 104 | USB-C Hub | 4.51 | 4.8 |
| 105 | Webcam Pro | -2.95 | 4 |
| 106 | Portable SSD | 4.12 | 4.1 |
| 107 | Laptop Stand | -3.37 | 2.5 |
| 108 | Bluetooth Speaker | 4.68 | 4.2 |
+------------+--------------------+------------+--------------+

Tasks:

Write the query for following tasks - 

1. Show a clean_rating column using ABS() to correct negative ratings.

2. Add a rounded_rating column that rounds clean_rating to 1 decimal place using ROUND().

3. Show a deviation column representing the absolute difference between rounded_rating and system_b_avg, rounded to 2 decimal places.

4. Filter the results to show only products where the deviation exceeds 0.5.

5. Order by deviation descending.

### Output
 product_name | clean_rating | rounded_rating | deviation 
----------------+--------------+----------------+-----------
 Webcam Pro | 2.95 | 3.0 | 1.00
 Gaming Headset | 3.89 | 3.9 | 0.90
 Laptop Stand | 3.37 | 3.4 | 0.90
 Wireless Mouse | 4.76 | 4.8 | 0.80
(4 rows)

## Solution

```js
select 
 product_name,
 abs(raw_rating) as clean_rating,
 round(abs(raw_rating),1) as rounded_rating,
 round(abs(round(abs(raw_rating),1)-system_b_avg),2) as deviation
from products 
where round(abs(round(abs(raw_rating),1)-system_b_avg),2) > 0.5
order by deviation desc
```
