## Problem Statement

Akash maintains an employee database where each document stores an employee&#39;s name, department, and salary. He wants to analyze the total and average salaries per department.

Write a MongoDB aggregation query using $group to:

 
 Group employees by their department.

 

 
 Calculate the total salary of employees in each department.

 

 
 Calculate the average salary in each department.

 

 
 Return the result sorted by department name in ascending order.

 

Sample Collection (employees):

[

 { "_id": 1, "name": "Alice", "department": "HR", "salary": 45000 },

 { "_id": 2, "name": "Bob", "department": "IT", "salary": 60000 },

 { "_id": 3, "name": "Charlie", "department": "IT", "salary": 55000 },

 { "_id": 4, "name": "David", "department": "HR", "salary": 50000 },

 { "_id": 5, "name": "Eve", "department": "Finance", "salary": 70000 }

]

 

### Output
[
 { "department": "Finance", "total_salary": 70000, "average_salary": 70000 },
 { "department": "HR", "total_salary": 95000, "average_salary": 47500 },
 { "department": "IT", "total_salary": 115000, "average_salary": 57500 }
]

## Solution

```js
db.employees.aggregate([
  {
    $group: {
      _id: "$department",
      total_salary: { $sum: "$salary" },
      average_salary: { $avg: "$salary" }
    }
  },
  {
    $sort: {
      _id: 1
    }
  },
  {
    $project: {
      _id: 0,
      department: "$_id",
      total_salary: 1,
      average_salary: 1
    }
  }
]);
```
