Your goal is to complete a Node.js Express server that functions as a simple, dynamic calculator. You will implement the logic for a single API endpoint that performs an arithmetic operation based on parameters passed directly in the URL.

Detailed Requirements:

 
 Endpoint: You must implement the GET endpoint with the path /calculate/:operation/:a/:b

 
 : operation: A string representing the calculation to perform (e.g., add).

 :a: The first number for the calculation.

 :b: The second number for the calculation.

 
 

 
 Input Handling: The numbers a and b will come from the URL as strings. You must convert them into numbers before performing any calculations.

 

 
 Successful Operations (Status 200) : 

 
 Your endpoint must correctly handle the following four operations:
 
 add: Adds a and b.

 subtract: Subtracts b from a.

 multiply: Multiplies a and b.

 divide: Divides a by b.

 
 

 If the operation is valid and successful, your server must respond with:
 
 A status code of 200.

 A JSON object containing the result, like this: { "result": &lt;calculated_value&gt; }.

 
 

 Example Request: GET /calculate/add/10/5

 Example Response Body: JSON
 
{ "result": 15 }

 

 
 

 
 Error Handling (Status 400) : Your API must handle two specific error cases by sending a status code of 400 and a JSON error message.

 
 
 Invalid Operation: If the :operation parameter is anything other than add, subtract, multiply, or divide.

 Division by Zero: If the :operation is divide and the second number (b) is 0.
