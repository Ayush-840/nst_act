## Problem Statement

Write a program that takes an integer n as input and prints a diamond pattern of 2n-1 height.

### Input
First line will contain an integer n representing the number of rows in the top half of the diamond.

### Output
Print the diamond pattern of 2n-1 height.

### Example
Input
5

Output

for (let i = 1; i <= n; i++) {
    console.log(" ".repeat(n - i) + "* ".repeat(i).trimEnd());
}
for (let i = n - 1; i >= 1; i--) {

}
