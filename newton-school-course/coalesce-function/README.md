## Problem Statement

The finance team at TechKart wants to review performance across different product categories. They maintain a table ProductSales with sales details including optional discounts.
Your task is to write a SQL query that:

 * Calculates the total sales amount per category as total_sales

 * Calculates the total discount per category as total_discount, treating NULL discounts as 0 using COALESCE()

 * Displays category, total_sales, and total_discount

&lt;schema&gt; [ { "name": "ProductSales", "columns": [ {"name": "id", "type": "SERIAL PRIMARY KEY"}, {"name": "product_name", "type": "TEXT"}, {"name": "category", "type": "TEXT"}, {"name": "sales_amount", "type": "NUMERIC(10, 2)"}, {"name": "quantity_sold", "type": "INTEGER"}, {"name": "sale_date", "type": "DATE"}, {"name": "discount", "type": "NUMERIC(5, 2)"} ] } ] &lt;/schema&gt;

### Output
Order of columns should be as follows:
category
total_sales
total_discount

## Solution

```js
SELECT 
    category,
    SUM(sales_amount) AS total_sales,
    SUM(COALESCE(discount, 0)) AS total_discount
FROM 
    ProductSales
GROUP BY 
    category;
```
