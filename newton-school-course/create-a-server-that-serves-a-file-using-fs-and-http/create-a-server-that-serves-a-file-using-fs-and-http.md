## Problem Statement

Create a basic Node.js server that listens on port 3000. When the user visits the route /read, it should:

 
 Read the contents of a file named message.txt using the fs module.

 

 
 Send the file content as the response to the client.

 

 
 You should use the Async version of read file not the sync version.

 

All other routes should return a 404 response with the message "Not Found".

The file message.txt is already present in the same directory and contains some sample content.

## Solution

```js
const fs = require('node:fs');
const path = require('node:path');
const PORT = 3000;
const FILE_PATH = path.join(__dirname, 'message.txt');
const server = http.createServer((req, res) => {
    const parsedUrl = new URL(req.url, `http://${req.headers.host || 'localhost'}`);
    const pathname = parsedUrl.pathname;
    const method = req.method;
    if (method === 'GET' && pathname === '/read') {
        // Async read operation using fs.readFile
        fs.readFile(FILE_PATH, 'utf-8', (err, data) => {
            if (err) {
                res.writeHead(500, { 'Content-Type': 'text/plain' });
                res.end('Internal Server Error');
                return;
            }
            res.writeHead(200, { 'Content-Type': 'text/plain' });
            res.end(data);
        });
    } else {
        res.writeHead(404, { 'Content-Type': 'text/plain' });
        res.end('Not Found');
    }
});
server.listen(PORT, () => {
    console.log(`Server listening on port ${PORT}`);
});
module.exports = server;
```
