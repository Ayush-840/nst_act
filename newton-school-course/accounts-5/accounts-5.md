## Problem Statement

A bank manager wants to analyze branch performance.
First, calculate the average balance for each branch. Then, display only those branches whose average balance is greater than 60,000.

Use a subquery in the FROM clause to create a derived table containing branch-wise averages.

ACCOUNTS

+------------+---------------+----------+---------+
| account_id | customer_name | branch | balance |
+------------+---------------+----------+---------+
| 101 | Aarav | Pune | 50000 |
| 102 | Diya | Pune | 80000 |
| 103 | Vivaan | Mumbai | 45000 |
| 104 | Ananya | Mumbai | 90000 |
| 105 | Ishaan | Delhi | 70000 |
| 106 | Meera | Delhi | 60000 |
+------------+---------------+----------+---------+

Write a SQL query to display:

 branch

 avg_balance (round to 2)

for branches whose average balance is greater than 60,000.

Use a subquery in the FROM clause (derived table).

### Output
 branch | avg_balance 
--------+-------------
 Mumbai | 67500.00
 Pune | 65000.00
 Delhi | 65000.00
(3 rows)

## Solution

```js
SELECT 
    branch, 
    ROUND(avg_balance, 2) AS avg_balance
FROM (
    SELECT 
        branch, 
        AVG(balance) AS avg_balance
    FROM ACCOUNTS
    GROUP BY branch
) AS branch_averages
WHERE avg_balance > 60000;
```
