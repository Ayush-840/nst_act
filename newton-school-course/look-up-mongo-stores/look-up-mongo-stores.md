## Problem Statement

Saumitra runs an online bookstore that stores orders and customers in separate collections.

customers collection:

[

 { "_id": 1, "name": "John Doe", "email": "john@example.com" },

 { "_id": 2, "name": "Jane Smith", "email": "jane@example.com" },

 { "_id": 3, "name": "David Lee", "email": "david@example.com" }

]

orders collection:

[

 { "_id": 101, "customer_id": 1, "book_title": "MongoDB Basics", "price": 500 },

 { "_id": 102, "customer_id": 2, "book_title": "Advanced Node.js", "price": 750 },

 { "_id": 103, "customer_id": 1, "book_title": "JavaScript in Depth", "price": 650 },

 { "_id": 104, "customer_id": 3, "book_title": "Python for Data Science", "price": 800 }

]

Write a MongoDB Aggregation Pipeline using $lookup to display each order with the customer&rsquo;s name and email.

### Output
[
 { book_title: 'MongoDB Basics', price: 500, customer_name: 'John Doe', email: 'john@example.com' },
 { book_title: 'Advanced Node.js', price: 750, customer_name: 'Jane Smith', email: 'jane@example.com' },
 { book_title: 'JavaScript in Depth', price: 650, customer_name: 'John Doe', email: 'john@example.com' },
 { book_title: 'Python for Data Science', price: 800, customer_name: 'David Lee', email: 'david@example.com' }
]

## Solution

```js
db.orders.aggregate([
  {
    $lookup: {
      from: "customers",
      localField: "customer_id",
      foreignField: "_id",
      as: "customer_info"
    }
  },
  {
    $unwind: "$customer_info"
  },
  {
    $project: {
      _id: 0,
      book_title: 1,
      price: 1,
      customer_name: "$customer_info.name",
      email: "$customer_info.email"
    }
  }
]);
```
