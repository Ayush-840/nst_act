## Problem Statement

Given an undirected, unweighted graph with $N$ vertices and $M$ edges, find the shortest distance (number of edges) from a start vertex $S$ to a destination vertex $E$. If $E$ is unreachable from $S$, output $-1$.

### Input
The first line contains a single integer $T$ ($1 \le T \le 10^5$) --- the number of test cases.

For each test case:
The first line contains four space-separated integers $N$, $M$, $S$, and $E$ ($2 \le N \le 10^5$, $0 \le M \le 2 \cdot 10^5$, $1 \le S, E \le N$).
Each of the following $M$ lines contains two space-separated integers $U$ and $V$ ($1 \le U, V \le N$, $U \neq V$), representing an edge between vertices $U$ and $V$.

It is guaranteed that there is at most one edge between any pair of vertices.
The sum of $N$ over all test cases does not exceed $2 \cdot 10^5$, and the sum of $M$ over all test cases does not exceed $2 \cdot 10^5$.

### Output
For each test case, print a single integer on a new line: the minimum number of edges to travel from $S$ to $E$, or $-1$ if no path exists.

### Example
Input:
1
5 5 1 5
1 2
1 3
2 4
3 4
4 5

Output:
3

Input:
1
5 0 1 5

Output:
-1
