## Problem Statement

You are given an array of integers, and your task is to determine whether each number is a prime number or not. You assigned this task to your junior, he wrote the following code but it contains an error. You are tasked to debug the errors and correct the function.

### Input
The first line of input contains an array of numbers

### Output
The first line of output shows an array containing a list if a number is Prime or not

### Example
Input:
[2, 4, 5, 6, 7, 8]

Output:
[ 'Prime', 'Not Prime', 'Prime', 'Not Prime', 'Prime', 'Not Prime' ]

## Solution

```js
function isPrime(num) {
  if (num <= 1){
    return false
  }
  for (let i = 2; i <= Math.sqrt(num); i++) {
    if (num % i === 0) {
      return false;
    }
  }
  return true; 
}

function checkPrimes(numbers) {
    return numbers.map(num => isPrime(num) ? "Prime" : "Not Prime");
}
```
