## Problem Statement

We have two collection

Collection: users

[

 { "_id": 1, "name": "Riya", "city_id": 101 },

 { "_id": 2, "name": "Arjun", "city_id": 102 },

 { "_id": 3, "name": "Diya", "city_id": 101 }

]

Collection: cities

[

 { "_id": 101, "city": "Delhi", "state": "Delhi" },

 { "_id": 102, "city": "Mumbai", "state": "Maharashtra" }

]

Write a MongoDB query to fetch all users along with the complete city information of where they live.

### Output
[
 { "_id": 1, "customer": "Riya", "amount": 1200, "status": "Delivered" },
 { "_id": 2, "customer": "Riya", "amount": 800, "status": "Pending" },
 { "_id": 3, "customer": "Arjun", "amount": 1500, "status": "Delivered" },
 { "_id": 4, "customer": "Diya", "amount": 600, "status": "Cancelled" }
]

### Example
 Sample Output:
 {
 _id: 1,
 name: 'Riya',
 city_id: 101,
 city_info: [ { _id: 101, city: 'Delhi', state: 'Delhi' } ]
 }

## Solution

```js
db.users.aggregate([
  {
    $lookup: {
      from: "cities",
      localField: "city_id",
      foreignField: "_id",
      as: "city_info"
    }
  }
]);
```
