## Problem Statement

Create an event tracker for a food delivery app.

Requirements:

 * Create an instance of EventEmitter named deliveryTracker

 * Setup a listener for the event named &#39;delivered&#39;

 * When the event fires, It should print: "Food has arrived! Enjoy your meal."

 * Trigger (emit) the &#39;delivered&#39; event

## Solution

```js
const EventEmitter = require('events');
const deliveryTracker = new EventEmitter();
deliveryTracker.on('delivered', () => {
    console.log('Food has arrived! Enjoy your meal.');
});
deliveryTracker.emit('delivered');
module.exports = { 
    deliveryTracker: typeof deliveryTracker !== 'undefined' 
        ? deliveryTracker 
        : null 
};
```
