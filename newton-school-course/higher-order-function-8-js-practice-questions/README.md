## Problem Statement

Write a function called parent that takes a callback function as an argument.

The parent function should return a new function that, when invoked with a number (num), calls the callback function with that number as its argument and returns the result.

### Input
first line of input is a callback function in oneline
second line of input is a digit num which represents the second argument passed to the function parent

### Output
the output represents the result of invocation of callback function with num as its argument.

Note:- this function is automatically invoked from the system

### Example
Input
(num) =&gt; num * 2
5
Output
10

Explanation
When the parent function is invoked with a callback that multiplies a number by 2, it returns a new function. When this new function is called with the number 5, it invokes the callback with 5 as its argument. The callback multiplies 5 by 2, returning 10.

## Solution

// Your code here
function parent(callback){
    return function(num){
        callback(num)
    }


}
