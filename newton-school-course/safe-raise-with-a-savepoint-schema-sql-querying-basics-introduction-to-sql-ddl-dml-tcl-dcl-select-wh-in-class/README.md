## Problem Statement

You are given an employees table (emp_id, emp_name, department, salary). Do all of the following inside one transaction:

The employees table initially contains:

+--------+--------------+------------+--------+
| emp_id | emp_name | department | salary |
+--------+--------------+------------+--------+
| 1 | Aarav Sharma | Sales | 60000 |
| 2 | Priya Nair | Intern | 20000 |
| 3 | Rahul Verma | Tech | 52000 |
+--------+--------------+------------+--------+

 * Give every employee a raise of 5000.

 * Set a savepoint named sp1.

 * Delete every employee in the Intern department.

 * Undo just that delete with ROLLBACK TO sp1 (the raise must stay).

 * COMMIT the transaction.

Then return every employee (emp_id, emp_name, department, salary) .

### Output
BEGIN
UPDATE 3
SAVEPOINT
DELETE 1
ROLLBACK
COMMIT
 emp_id | emp_name | department | salary 
--------+--------------+------------+--------
 1 | Aarav Sharma | Sales | 65000
 2 | Priya Nair | Intern | 25000
 3 | Rahul Verma | Tech | 57000
(3 rows)

## Solution

```js
begin;
update employees set salary=salary+5000;
savepoint sp1;
Delete from employees
where department='Intern';
ROLLBACK TO sp1;
COMMIT;

select emp_id, emp_name, department, salary from employees;
```
