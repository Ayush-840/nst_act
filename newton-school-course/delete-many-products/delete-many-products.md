## Problem Statement

You are managing a products collection in MongoDB with documents like the following:

{
 "name": "Laptop",
 "price": 60000,
 "category": "Electronics",
 "inStock": false
}

Write a MongoDB query using deleteMany() to delete all products where:

The category is "Electronics"

AND

The item is not in stock (inStock: false).

## Solution

```py
db.products.deleteMany({
  category: "Electronics",
  inStock: false
});
```
