## Problem Statement

You are given an undirected graph with n vertices and m edges. Perform a Depth First Traversal of the graph.

### Input
User Task:
Since this will be a functional problem, you don't have to take input. You just have to complete the function dfsOfGraph() that takes two parameter n representing number of nodes and a 2D array of edges of length m.

Custom Input:
First line contains two integers n and m representing number of nodes and number of edges.
Next m lines will contain two space separated integers u and v representing undirected edge between them.

### Output
Returns a list containing the DFS traversal of the graph.

### Example
Input:
5 4
0 2
0 3
0 1
2 4

Output:
0 2 4 3 1

Explanation:
0 is connected to 2, 3, 1.
1 is connected to 0.
2 is connected to 0 and 4.
3 is connected to 0.
4 is connected to 2.
so starting from 0, it will go to 2 then 4,
and then 3 and 1.
Thus dfs will be 0 2 4 3 1.

## Solution

```py
def dfsOfGraph(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)

    visited=[False] *n
    trav=[]
    def dfs(node):
        visited[node]=True
        trav.append(node)
        for neigh in adj[node]:
            if not visited[neigh]:
                dfs(neigh)
    # dfs(0)
    for i in range(n):
        if visited[i]==False:
            dfs(i)
    return trav
```
