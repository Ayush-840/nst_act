## Problem Statement

Scenario: The analytics team needs two reports. The first should show every account&#39;s balance alongside the bank-wide average for quick comparison. The second should summarise total deposits by branch so leadership can identify which branches hold the most funds.

Tasks:

1. Create a derived table that calculates the total balance held by each branch. Return only those branches whose total balance exceeds 200,000.

2. Extend the query in Task 1 with a WHERE clause on the outer query to return only branches whose total_balance exceeds 2,00,000.

3. For each qualifying branch, display branch, total_balance, and diff_from_overall, calculated as the branch&#39;s total balance minus the overall average account balance across all accounts.

## Solution

```js
// ─── 1 ───
SELECT
    branch,
    total_balance,
    total_balance - (
        SELECT AVG(balance)
        FROM accounts
    ) AS diff_from_overall
FROM (
    SELECT
        branch,
        SUM(balance) AS total_balance
    FROM accounts
    GROUP BY branch
)
WHERE total_balance > 200000;
```
