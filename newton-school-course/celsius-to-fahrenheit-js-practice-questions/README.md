## Problem Statement

Given a temperature C in Celsius, your task is to convert it into Fahrenheit and print its value using the following equation:- T&deg;F = T&deg;C &times; 9/5 + 32

### Input
Input is an integer value representing Temperature in Celcius 

Constraints
-273.15 Note: It is guaranteed that C will be a multiple of 5.

### Output
Print an integer containing the converted temperature in Fahrenheit.

### Example

25

77

Sample Input:-
-40
